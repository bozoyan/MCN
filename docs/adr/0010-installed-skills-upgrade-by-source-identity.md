# Installed skills upgrade by source identity

An Installed Skill records a stable source identity and source version rather
than relying on its novel-local call name. When an installation collides with
an existing call name, the user explicitly replaces the existing skill or
renames the new one. A renamed skill remains eligible for upgrades from its
original source. Upgrades are explicit per-novel actions and preserve the
installation's local call name, enabled state, and sort order.
