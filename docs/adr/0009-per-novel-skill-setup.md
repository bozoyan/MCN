# Skill selection is configured per novel

Every novel has a Novel Skill Setup flow for choosing which catalog and private
skills to install. The same flow replaces automatic bundled-skill availability
and supports filtering skills by category and tag, so configuration stays
explicit and scoped to the novel that will execute the skills. Setup is
skippable; a novel with no installed skills remains usable. Categories are
platform-maintained, dictionary-backed, and singular per skill; tags are
author-provided and may be corrected during marketplace review.
