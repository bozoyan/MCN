# AI creates Seasons only for explicit user intent

AI may call `Create /screenplay/seasons` only when the current user task clearly asks to add a Season, continue into a next Season, or plan a multi-Season structure. Exceeding a planned Episode count, increasing story length, an existing multi-Season structure, or AI's own structural preference may support a suggestion but does not authorize creation. This is an orchestrator and screenplay-guide behavior rule rather than an unverifiable confirmation field or dynamic tool schema.
