# Season deletion is user-only

AI may create and edit Seasons, but it cannot delete one. A Season deletion cascades through every Episode, Beat, Scene, cast link, and screenplay element in that Season, while the first release has no recovery interface. The operation is therefore available only from the explicit Season management UI, where the user sees the affected scope and confirms it; conversational confirmation through AI does not unlock the Remove path. Season reordering is separately restricted by ADR-0029.
