# Skill execution is novel-bound

Official skills, approved marketplace listings, and private skills in a user's
cross-novel Skill Library are not globally available. Catalog skills become
usable through an explicit Novel Installation, while a Novel Local Skill is
created directly in its owning novel. Every executable skill belongs to one
novel, and each installation keeps a content snapshot, so no catalog update
can silently affect another novel. Saving a Novel Local Skill to the Skill
Library creates an independent private copy and retains the original skill.
