# Cross-work reads remain available to every valid local work

Screenplay adaptation can name a Source Novel, but AI sessions may read any valid local work when the caller supplies its stable `work_id`. We choose explicit, broad local read access over a source-only allowlist so writers can draw from multiple local references without changing the source relationship; cross-work writes remain prohibited.

## Considered Options

- Restrict reads to the Source Novel.
- Allow explicit reads of every valid local work.
