
## ModelScope LoRA 触发词 + BizyAir 双供应商 + 多密钥池

- 新增 `lib/shared/services/ai/modelscope_catalog.dart`：运行时读外置 `modelscope_models.json`（cwd 优先，回退可执行文件同目录），Model→prompt 反查触发词，`prefixTriggers()` 把生效 LoRA 触发词去重前置到提示词；读取失败退化为空清单不阻塞出图。已在 `ModelScopeImageClient.generate()` 接入。
- 新增两个独立供应商类型 `bizyair_modelzoo` / `bizyair_webapp`，各挂 `ImageProtocol.bizyair_modelzoo_image` / `bizyair_webapp_image`；modelzoo 渠道表 12 个端点（6 通道 × t2i/i2i），webapp 渠道表 2 个应用（57932/57807），新增应用只需在渠道表加一条。
- 新增 `lib/shared/services/ai/image/bizyair.dart`：modelzoo 走 `/v1/modelzoo/tasks/openapi/<通道>`，webapp 走 `/v1/webapp/task/openapi/create`（`X-Bizyair-Task-Async: enable`）；首轮等 60s 再 5s 轮询；参考图本地/data URI 经 `https://b.slas.cc/api/bizyair/upload` 转存。
- 新增 `lib/shared/services/ai/bizyair_keys.dart` 多密钥池：Key 字段支持「txt 路径 / 多把内联」，每行一把、`#` 注释、兼容 `KEY=value`；游标持久化 `${supportRoot}/bizyair_key_cursors.json`（按供应商 id 分槽），任务成功后 +1 轮转，提交失败串行换 key 重试；空 Key 时回退 `~/PY/2026/bizyair/bizyair_BOZO.txt` 等默认池文件与 `BIZYAIR_API_KEYS`。
- `BizyAirImageClient` 增加按供应商维度的串行任务队列（一把 key 同时只跑一个任务），前一个任务失败不阻塞后续。
- UI：`lib/shared/widgets/production/modelscope_lora_picker.dart` 清单选择器（搜索 + 分类分组 + 触发词预览），接入 LoRA 面板「从清单选择」；新增 i18n key（`production.imageLoraPick*` / `imageLoraTrigger`）。
- 测试：`modelscope_catalog_test`、`bizyair_image_test`、`bizyair_keys_test`、`modelscope_lora_picker_test`；9 个相关套件 97 用例全绿，`fvm dart analyze` 无 error（仅 third/ 与 channels 既有 info）。
- 环境注意：跑 `flutter test` / analyze 需注入 `$HOME/.cargo/bin:$HOME/.rustup/toolchains/1.97.1-.../bin` 到 PATH 并加 `--no-pub`，否则 pub get 或 rust native asset 构建会卡住。
