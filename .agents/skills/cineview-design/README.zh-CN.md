# Cineview 设计参考

这是一份写给 AI 读的技能，帮你用 Cineview 做落地页。它不会拿到素材就直接开做，而是先和你沟通：
- 了解你要做什么；
- 给你两三个方向，建议做几幕；
- 一幕一幕讨论每一幕讲什么、读者看到什么、用哪些素材、还缺什么；
- 最后整理成一张分镜表和一份素材清单，你确认后才开始制作。

其余文件是它给建议时参考的资料库：能直接用的写法、各种视觉风格、排版、41 种设计参考的搭配观察，以及整页结构的例子。

这些都只是参考，不是模板，也不是规定。例子里的字体和颜色都写成变量，套上你自己的品牌或风格，同样的结构会呈现完全不同的样子。

技能按 npm 上的 cineview 2（`cv-*` 元素写法）编写。1.0.x 是另一套 React 写法，不要把两者的例子混在一起用。

## 怎么用

- **Claude Code**：把整个 `cineview-design` 目录复制到你项目的 `.claude/skills/` 下，Claude 会在相关任务里读取它。
- **Cursor、Codex 等其它工具**：让 AI 先读 `skills/cineview-design/SKILL.md`，再按需要读其中几份。
- **直接对话**：把 `SKILL.md` 和你要用的那几份文件贴给 AI。

然后照常说你想做什么就行，比如「我想给我的摄影展做个页面，有八张照片」。AI 会一个问题一个问题地问你，每个问题都附上它的建议，你同意就说「好」，不同意就直接改。你的产品、素材和喜好说得越具体，做出来的页面就越像你自己的。

## 里面有什么

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 目录、框架本身的几条规律，以及一些常有帮助的想法 |
| `framework.md` | 框架速查：元素、属性、效果预设、时间规则、事件、脚本接口 |
| `styles.md` | 13 种视觉方向（产品、编辑、霓虹、海报、生活、纪实、童趣、奢华、粗野、复古终端、瑞士网格、自然、电影感）：字体、色板、标题、母题、动效，以及适合什么产品 |
| `conversation.md` | 怎么和你沟通：了解需求、给方向、定几幕、逐幕定内容和素材、整理分镜表和素材清单（先读这份） |
| `video.md` | 视频：素材准备、随滚动播放、胶片条、手机里的拖动演示 |
| `transitions.md` | 视频背景、点击播放后切换到下一幕、用视频做转场，以及不用视频的转场做法 |
| `images.md` | 图片：揭开、双色、对焦、缓推、分镜缩略图、图卡 |
| `type.md` | 文字：多种标题处理、断行控制、打字机、按行入场、字重变化、数字滚动 |
| `line-art.md` | 线稿和辅助元素 |
| `drawing.md` | 用时间线驱动自己画的 Canvas、WebGL、SVG |
| `colour.md` | 配色随场景或滚动变化、可读性 |
| `layouts.md` | 32 种排版 |
| `combinations.md` | 41 种设计参考在各种模式下放在一起的表现：哪些常常好看、哪些容易互相干扰，以及原因 |
| `drag.md` | 拖动模式，以及把拖动页嵌进滚动页 |
| `pages.md` | 不同类型页面的结构例子 |
| `references.md` | 41 种设计参考，每种一行 |
| `checks.md` | 双语切换、刷新不闪、浏览器里的检测方法 |
