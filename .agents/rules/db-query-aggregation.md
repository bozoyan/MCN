# 数据库查询聚合规则

- 统计数量、最大值、最小值、总和、存在性判断等聚合查询，必须优先使用 SQL 聚合（`COUNT`、`MAX`、`MIN`、`SUM`、`EXISTS` / `LIMIT 1`）。
- 禁止为了聚合结果读取完整行列表后在 Dart 内存中循环计算，尤其是包含正文、消息、图片、JSON、embedding、历史记录等大字段的表或 view。
- 如果现有 DAO 只有 `getAll()`，应新增专用聚合方法，而不是复用 `getAll()`。
- 只有调用方确实需要逐条展示或处理完整对象时，才允许读取完整列表。
- 新增首页、侧栏、仪表盘、统计卡片等启动路径查询时，必须检查是否可以用 SQL 聚合，避免冷启动加载大字段。
