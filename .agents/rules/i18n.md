# i18n 规则

- 新增、修改、删除用户可见文案时，必须同步检查 i18n；不要只改单个 widget 中的硬编码字符串。
- Locale key 常量文件：`lib/shared/localization/locale_keys.dart`
- 翻译文件按 namespace 拆分：`assets/translations/en/*.json`、`assets/translations/zh-CN/*.json`
- 在 widget 中优先使用 `context.t(LocaleKeys.xxx)` 或等价封装，不要直接写死文案，除非该文本明确不参与本地化。

## Widget 测试中的 i18n 初始化

- 只要被测 widget 或其子树会调用 `context.t(...)` / `tr(...)`，测试必须初始化 EasyLocalization；不要为了“不是在测试文案”而省略 i18n wrapper，否则会在构建时空指针。
- `setUpAll` 中固定写：

```dart
SharedPreferences.setMockInitialValues({});
await EasyLocalization.ensureInitialized();
```

- 测试 wrapper 固定使用 `MergingAssetLoader`，并把 EasyLocalization 的 delegate/locale 传给 `MaterialApp`：

```dart
Widget _wrap(Widget child) {
  return EasyLocalization(
    supportedLocales: const [Locale('en')],
    path: 'assets/translations',
    assetLoader: const MergingAssetLoader(),
    fallbackLocale: const Locale('en'),
    startLocale: const Locale('en'),
    child: Builder(
      builder: (context) {
        return MaterialApp(
          localizationsDelegates: context.localizationDelegates,
          supportedLocales: context.supportedLocales,
          locale: context.locale,
          theme: RevericThemeData.reveric.toThemeData(),
          home: RevericTheme(
            data: RevericThemeData.reveric,
            child: Scaffold(body: child),
          ),
        );
      },
    ),
  );
}
```

- 如果测试需要 Riverpod，把 `ProviderScope` 放在 `EasyLocalization` 外层或 `MaterialApp` 外层均可；优先沿用同目录已有测试的包裹顺序。
- 这类测试不需要断言翻译文案；i18n wrapper 的职责只是提供真实构建上下文。
