# 原创初始化流程

在当前作品上下文中的 `type` 为 original 且用户确认“从零原创”时使用。本流程只确认后期难改的基础决策；角色细节、支线和章节可渐进补齐。

## 1. 先确认故事承诺

先读现有简介、分类、标签、世界观、角色、大纲和章节。用 AskUser 确认：

1. 题材与目标读者。
2. 一句话故事承诺：读者持续追读时，稳定获得什么体验。
3. 主角要达成的核心目标，以及阻止其达成的核心对立。

已有内容足以回答时，展示理解并让用户确认，不要从空白重问。

## 2. 确认不可逆结构

按题材选择 2–3 个最关键的维度分轮确认：

- 世界/舞台与社会秩序。
- 能力、资源、职业或竞争规则，以及硬上限和代价。
- 主要势力、关系格局和长期冲突。
- 信息边界：谁知道什么，真相如何逐步揭示。
- 现实、史实、行业或科学边界。

只问会影响全书、后期修改代价高的事项。不要为了补全模板而追问细枝末节。

## 3. 形成最小创作底座

根决策与不可逆结构确认后：

1. 先完成书名所需的舞台、卖点或核心对立钩子。
2. 确认书名、分类、标签、简介。
3. 确认章节字数、文风、视角、节奏和禁忌。
4. 将故事事实写入世界观、角色、势力或大纲资料；将稳定写作行为写为单维 AgentRule。

## 4. 结束检查

结束前确认以下内容可回答：

- 这本书向谁承诺什么体验？
- 主角为何必须行动，主要阻力是什么？
- 哪些世界或规则不能被后续章节推翻？
- AI 后续写作必须遵守哪些行为约束？

任一项为空时，只追问该项；不要重新跑完整流程。
