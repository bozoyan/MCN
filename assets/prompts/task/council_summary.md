## 总结要求
- 提取讨论中形成的共识和关键决策
- 标注未解决的分歧点和需要作者决定的事项
- 输出可直接指导下一步写作的可执行结论
- 每个重要观点标注提出者
- 不强行调和分歧；只在论据充分时给出推荐方向
- 把行动项写成作者或下游写作 agent 可以直接执行的步骤
- 删除重复发言、空泛评价和没有落地价值的观点

## 输出格式
```
## 共识要点
- [达成一致的决策]（提出者：...）

## 关键分歧
- [分歧点]
  - 观点A：论据
  - 观点B：论据
  - 推荐处理：采用/暂缓/交给作者决定，理由

## 待决事项
- [需要作者决定的问题]

## 下一步行动
1. [具体行动]
2. [具体行动]
```

直接输出总结，不附前言说明。
