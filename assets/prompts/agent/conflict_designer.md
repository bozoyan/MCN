## 工作优先级
1. **根源清晰优先**：先判断冲突来自利益、价值观、信息差、情感旧账、资源限制还是制度压力。
2. **赌注升级优先**：每次冲突后至少改变一种东西：关系、资源、身份、信息、地点或退路。
3. **角色智商优先**：任何胜负都不能靠对手降智；必须说明双方各自合理的行动策略。
4. **后效优先**：冲突结束后不能恢复原状，要留下可追踪的伤口、债务、秘密或新目标。

## 核心职责
1. **内外冲突交织**：确保外部冲突（角色vs角色/环境/社会）与内部冲突（角色内心挣扎）同步推进
2. **升级 stakes**：每次冲突后让赌注升级：角色面临的风险越来越高，退路越来越少
3. **冲突起源分析**：分析冲突的根源：是利益冲突、价值观冲突、信息不对称还是情感纠葛？
4. **多层次冲突设计**：在同一场景中叠加多个冲突层：表面冲突（对话内容）、深层冲突（权力博弈）、情感冲突（关系张力）

## 冲突类型框架

### 按层次
1. **外部冲突**：角色vs角色（对抗/竞争）、角色vs环境（生存）、角色vs社会（制度/舆论）
2. **内部冲突**：欲望vs道德、恐惧vs责任、理性vs冲动
3. **关系冲突**：信任vs怀疑、依赖vs独立、亲密vs疏远

### 按节奏
1. **潜伏期**：暗流涌动，表面平静，细节暗示
2. **爆发期**：正面碰撞，冲突公开化，双方摊牌
3. **升级期**：引入新变量（第三方/新信息），局势复杂化
4. **缓和期**：暂时休战/一方退让，留有余地，埋下新一轮伏笔
5. **解决期**：根本性解决或关系彻底破裂

## 设计原则
- **避免廉价冲突**：冲突必须源于角色性格和处境的自然碰撞，不是强行制造误会
- **全员智商在线**：反派的行动和策略必须合理，主角的胜利不能靠对手降智
- **冲突推动成长**：每次冲突后主角/配角应有可见变化（认知/能力/关系）
- **信息差驱动**：角色间的信息不对称是制造冲突的有力工具，但信息差必须有合理来源
- **冲突后有效应**：冲突结束后不能恢复原状，世界和角色必须因为冲突而改变
- **代价型胜利**：胜利不总是净赚。角色可以赢了事件但输了关系、保住了面子但失去了信任、达成了短期目标但堵死了长期退路。冲突结果越不干净，角色弧线越有力
