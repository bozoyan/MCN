# 章节密度与节奏规则

网文章节的字数、密度、段落和断章规则。

## 字数与爽点密度

- 每300字至少1个爽点/看点
- 每500字至少1个钩子
- 每1000-1500字至少1个完整悬念
- 目标字数允许区间为目标的±10%

## 叙事段长度

- 叙事段40-120字（3-5行手机屏）
- 对话段落天然短，不需并段
- 连续3个及以上短段（<40字）并列连排属于违规
- 短段仅在以下场景允许：(1)开场前300字反转金句 (2)章末钩子最后一句 (3)单章≤3个爆点短段
- 三个场景合计一章最多5个短段，超过即"堆砌电报体"
- 审核硬阈值：60%以上叙事段<40字 → 段落过碎，触发返工

## 80/20 断章硬尺

永远不要在一章里把本章故事讲完：写到80%，剩下20%留给下一章。

章末必须断在 action-climax 的那一刻：主角刚放大招尚未见效 / 刚拔刀尚未落下。

## 断章钩子轮换

每章结尾至少留下一个缺口。钩子必须轮换，不能每章都靠同一种悬念。

- 悬念类：关键信息即将揭露、秘密即将暴露、真相刚露一角。
- 危机类：强敌降临、陷阱触发、计划失败、背叛发生。
- 反转类：身份即将揭露、敌友转换、局势逆转、意外变故。
- 期待类：即将突破、宝物将到手、比赛结果、考核成绩。
- 情感类：误会将解、重逢/离别、告白回应、关系破裂。
- 信息类：重大消息、阴谋揭露、世界观重大信息、系统提示。

钩子必须在下一章前 1/3 处给反馈。可以不完全回收，但要让读者感觉上一章的问题被正面处理了。

## 节奏变化

```
紧张 → 缓解 → 新紧张 → 更紧张
```

- 紧张场景用短句加速（连续短句排比）
- 抒情或思考段落适当放慢（长句+感官细节）
- 避免单调的句子开头：不要连续以"他/她"开头
- 句式长短错落：长句用于环境/心理，短句用于动作/冲突

## 场景规范

- 新场景前100字让读者知道谁在场、在哪儿、发生什么
- 场景转换必须有过渡，禁止前一刻在A地、下一刻毫无过渡出现在B地
- 场景切换需通过感官细节建立新空间感

## 高潮前后规则

- **高潮前**：大高潮前3-5章必须有线索埋设
- **高潮后**：爆发后1-2章必须写出改变（主线推进、人设成长、关系变化），不能直接跳到下一个蓄压
