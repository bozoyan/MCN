# 从原文到制作交付：车站失物处

本附件是一份原创完整教学案例，展示同一场戏怎样经过覆盖核对、图片准备、分镜编排、提示词和结果验收。所有时长、人物外观与美术设定都是示例假设，不代表用户项目或已验证模型能力；没有生成图片或视频。

## 一、先确定原文与视觉事实

原文：

> 雨夜。失物处柜台，林岚在外侧，值班员在内侧。柜台上放着一只合着盖的蓝色铁盒。  
> 林岚：“蓝盒子，是我父亲留下的。”  
> 值班员把手压在盒盖上：“里面有什么？”  
> 林岚：“一枚断齿的钥匙。”  
> 值班员移开手，推过铁盒。林岚接住，打开盒盖。盒内是一枚断齿钥匙。  
> 林岚停住，抬眼看他。值班员：“他让我等你。”  
> 林岚合上盒盖，双手把盒子抱在身前。

为写出独立可读的示例，另假设已确认以下视觉设定：林岚约三十岁，齐下颌黑短发，深灰夹克；值班员约五十岁，短灰发、方脸，藏蓝工作外套。蓝色铁盒无锁扣，长边约两个手掌宽，铰链在靠值班员一侧，内衬灰布，内有一枚黄铜钥匙，钥匙齿列中间缺一齿。铁盒和钥匙没有需要读出的文字。

柜台沿东西方向，林岚站南侧、值班员站北侧；摄影机保持在两人连线的东侧，使林岚在双人镜头中偏左、值班员偏右。柜台北面是失物架，南侧有入口，西墙高窗透入微弱冷光，柜台上方暖白灯提供主光。窗口雨声低而连续。示例采用横幅；最终比例仍以配置为准。

原文确定事件和台词，视觉设定确定身份、物件结构与空间。摄影机的取景选择不能把钥匙提前露给观众，不能把“抱盒”提前到“接盒”之前。

## 二、覆盖与时长草案

为演示分段，暂按三个各 10 秒的分镜安排。假设实际模型可接受该时长；未查询时只能交付这个文字草案，配置保留未确认。

| 原文事项 | 分镜与 Shot | 必须留下的结果 |
|---|---|---|
| 林岚说明蓝盒来历 | A / Shot 1 | 原话完整，铁盒仍在柜台内侧 |
| 值班员压盖发问 | A / Shot 2 | 先压住再问，不开盒 |
| 林岚回答断齿钥匙 | A / Shot 3 | 原话完整，钥匙仍不可见 |
| 移手、推盒、接住 | B / Shot 1 | 同一个盒子沿柜台移动，林岚接稳 |
| 开盖、看清钥匙 | B / Shot 2–3 | 盖子确实打开，断齿可辨，没有取出钥匙 |
| 林岚停住抬眼、值班员回答 | C / Shot 1–2 | 反应在揭示之后，最后一句只说一次 |
| 合盖、双手抱盒 | C / Shot 3 | 盒盖合上，盒子由林岚持有，钥匙仍在盒内 |

播放顺序是 A → B → C。制作时可先准备共同人物、柜台和铁盒，再验证动作负载最高的 B；C 的开场最终对照 B 的实际采用结果。若 B 没有完整开盖，先修 B 或明确如何补完，不能让 C 从不存在的状态开始。

## 三、图片准备

资产计划不是实际绑定。复用已有的合格人物图和空间图；只有缺失或本场确需新状态时才制作。建议准备两个人物参考、一个柜台空间参考、同一铁盒的闭合与打开状态；钥匙细节在打开图仍看不清时再单独补图。A/B/C 是本文分镜简称，不是应用资源 ID。

### 柜台空场提示词

```text
雨夜的车站失物处，横向木柜台沿东西方向，南侧为访客区，北侧为值班区与失物架。摄影机位于柜台东侧，画面左侧留出南侧访客站位，右侧留出北侧值班员站位，台面横向连接双方。
北面失物架、西墙高窗与南侧入口保持明确空间关系。高窗透入微弱冷色夜光，柜台上方暖白灯照亮木台面。环境朴素、可辨认，画面无人，柜台上暂不摆蓝色铁盒，不生成标注、图例或新招牌文字。
```

### 蓝色铁盒的闭合与打开状态

```text
单个蓝色长方形铁盒的闭合参考图。长边约两个手掌宽，深蓝漆面略有使用磨痕，结构完整；没有锁扣，盒盖与盒身接缝清楚，铰链连接在后侧长边。四分之三角度能看清顶面、前沿与侧面。盒盖闭合，内部完全不可见。
置于中性浅灰背景，柔光照清结构与漆面，无人、无手，不出现标签文字或第二个盒子。
```

```text
已提供蓝色铁盒参考的打开状态，保持同一尺寸、磨痕、铰链与机位。盒盖沿后侧长边铰链向后打开，接近直立，盒体不旋转、不换边。灰布内衬上只有一枚黄铜钥匙，钥匙齿列中间缺一齿，齿边无遮挡、可辨认。
柔光照清盒内与钥匙轮廓，无手进入、不增加其他物件、锁扣或文字，不把钥匙放到盖子上。
```

### B 的首帧提示词

下例假设相应人物、柜台和闭盒图片已实际提供并核对：

```text
失物处柜台双人中景，机位在两人连线东侧，林岚在画面左侧的柜台外，值班员在右侧柜台内。沿用对应人物参考的面貌与服装、柜台参考的布局和暖白顶灯，西墙高窗的冷色夜光不变。
闭合蓝色铁盒仍在值班员一侧的台面，他的右掌压在盒盖中央。林岚双手停在自己一侧柜台边缘，尚未接触铁盒。盒盖铰链朝值班员方向，钥匙不可见；保留两人之间可推送铁盒的完整台面，不提前画成林岚已经拿到盒子。
```

若采用首尾帧，B 的目标尾帧应为盒子已在林岚一侧、盒盖打开、钥匙留在内衬上，林岚未取出钥匙。目标图只提供终点，不能替代视频中可见的推送与开盖。

## 四、三个分镜的完整提示词

下面每个文本块对应一条分镜，时间码分别从 0 开始。实际提交时加入已绑定的真实引用，并保持其身份；模型、输入模式与文件尚未确认时，不把文本当成已提交任务。

### 分镜 A：确认来历，10 秒

```text
人物沿用本场已确认外观：林岚齐下颌黑短发、深灰夹克；值班员短灰发、藏蓝工作外套。蓝色铁盒没有锁扣。低声雨声贯穿，无配乐或字幕。

Shot 1（双人中景·平视·固定·4s）
【0-4s】
首帧：雨夜失物处，机位在两人连线东侧。林岚位于左侧柜台外，值班员在右侧柜台内，闭合蓝色铁盒在值班员一侧的台面，盖子铰链朝他。暖白顶灯照亮台面，西墙高窗透入冷光。
[0-3.5s] 林岚看向值班员，用普通话清楚地说：“蓝盒子，是我父亲留下的。”双手留在自己一侧柜台边。值班员听着，不移动铁盒。
[3.5-4s] 林岚说完，短暂停顿，铁盒仍闭合。
结束状态：两人位置不变，铁盒仍在值班员一侧，钥匙不可见。

Shot 2（中近景·微俯拍·固定·3s）
【4-7s】
首帧：切到值班员与桌上铁盒，景别容纳脸、右手和盒盖；林岚在画外左侧。机位仍在人物轴线东侧，光源位置不变。
[4-5s] 值班员将右掌压到盒盖中央，铁盒没有移动或打开。
[5-7s] 值班员看向画外左侧，用普通话问：“里面有什么？”右掌保持在盖上。
结束状态：值班员已问完，右掌仍压住闭合盒盖。

Shot 3（近景·平视·固定·3s）
【7-10s】
首帧：切到林岚近景，机位保持轴线东侧，视线朝画外右侧，暖白顶灯与冷色环境底光不变。盒子不在这个取景内。
[7-9s] 林岚用普通话回答：“一枚断齿的钥匙。”语速自然，不增加解释。
[9-10s] 林岚说完，等待对方反应。只有连续低声雨声。
结束状态：林岚仍看向画外右侧，未伸手取物。
```

### 分镜 B：推盒与揭示，10 秒

```text
林岚齐下颌黑短发、深灰夹克；值班员短灰发、藏蓝工作外套。雨夜失物处，暖白顶灯与西墙高窗冷光保持。蓝色铁盒无锁扣，铰链朝值班员，内衬灰布，唯一黄铜钥匙齿列中间缺一齿。无对白、配乐或字幕，雨声低而连续。

Shot 1（双人中景·微俯拍·固定·4s）
【0-4s】
首帧：机位在两人连线东侧，林岚在左侧柜台外、值班员在右侧柜台内。闭合蓝色铁盒仍在值班员面前，右掌压盖，林岚双手尚未接触。台面和双方手部完整可见。
[0-1s] 值班员抬起压盖的右掌，将右手移至盒体靠自己一侧的侧边。
[1-3s] 值班员沿台面把铁盒平稳推向林岚，盒底始终接触木台面，铰链朝向不变。林岚双手从自己一侧伸出，分别扶住盒体两端；值班员在她接触并稳住盒子后收回右手。
[3-4s] 林岚将铁盒停在自己面前的台面，不抬起。只有盒底摩擦木台的声音，没有重摔声。
结束状态：闭合铁盒已在林岚一侧，双手扶住，值班员不再接触。

Shot 2（手部近景·微俯拍·固定·3s）
【4-7s】
首帧：铁盒仍在林岚面前，盒盖铰链朝远离她的一侧。林岚左手扶住盒体，右手移至靠自己一侧的盖沿；盒子尚未打开。沿用同一台面和灯光，人物脸不入画。
[4-6.5s] 林岚左手稳住盒体，右手抬起前沿，盒盖沿后侧铰链向值班员方向打开，停在接近直立的位置。灰布内衬和其中唯一的黄铜钥匙逐渐露出。
[6.5-7s] 林岚停止开盖，右手离开盖沿，停在盒体侧边，没有碰钥匙。只听到轻微铰链声。
结束状态：铁盒打开、仍在柜台上，钥匙留在内衬，未被拿起。

Shot 3（道具特写·俯拍·固定·3s）
【7-10s】
首帧：切入打开的铁盒内部，灰布上的唯一黄铜钥匙占据视觉中心，完整齿边及中间缺齿清楚可见，盒边和向后打开的盖子局部保留，手不遮住钥匙。
[7-10s] 保持清楚取景，让观众看见缺齿，钥匙不旋转、不复制、不被取出。雨声延续，铰链声已经结束。
结束状态：钥匙仍静置在灰布上，铁盒打开。
```

### 分镜 C：回答与抱盒，10 秒

```text
林岚齐下颌黑短发、深灰夹克，站在柜台南侧；值班员短灰发、藏蓝工作外套，站北侧。暖白顶灯和西墙高窗冷光保持，低声雨声连续，无配乐或字幕。

Shot 1（近景·平视·固定·2s）
【0-2s】
首帧：林岚近景，机位在人物轴线东侧，她低眼看向画面下方，打开的铁盒位于取景外的柜台上。
[0-2s] 林岚停顿后抬眼，视线移向画外右侧的值班员，没有开口。
结束状态：林岚已抬眼看向值班员，未移动身体位置。

Shot 2（近景·平视·固定·3s）
【2-5s】
首帧：切到值班员近景，保持轴线东侧，北侧失物架在背景，他看向画外左侧。灯光不变，林岚不入画。
[2-4.5s] 值班员用普通话轻声说：“他让我等你。”语速自然、吐字清楚。
[4.5-5s] 值班员说完，目光保持，未伸手取盒。
结束状态：值班员已经回答，仍在柜台内侧。

Shot 3（中景·微俯拍·固定·5s）
【5-10s】
首帧：切到林岚及她面前柜台的中景，脸、双手、打开的蓝色铁盒均入画，机位仍在轴线东侧。唯一钥匙仍在内衬，盖子向值班员一侧打开。
[5-7.5s] 林岚左手稳住盒体，右手将盒盖沿铰链向自己方向合下，盖子接触盒沿时发出一声轻响。
[7.5-10s] 盒盖合好后，林岚双手托住盒体两端，从台面抬起并抱在胸前下方。她没有打开盒子，也没有拿出钥匙。雨声延续。
结束状态：林岚双手抱着闭合铁盒，仍站在柜台外。
```

## 五、结果验收与交付

下列检查针对实际生成视频；本案例没有媒体，只能验证文字编排。若只能看静帧，动作顺序、台词、声音和口型仍待检查。

| 检查对象 | 可以定位的通过条件 |
|---|---|
| 原文覆盖 | 四句对白按原顺序各出现一次，未增加回答或旁白 |
| 信息揭示 | A 中钥匙未出现；B 先开盖再展示缺齿，缺齿确实能辨认 |
| 持有与状态 | 只推送一次；接住后再开盖，钥匙不出盒；C 合盖后才抱起 |
| 空间与身份 | 柜台两侧未互换，铁盒铰链不换边，机位反打仍在同一轴线侧 |
| 声音 | 推送为摩擦声，开盖为铰链声，合盖为轻响；没有暗示砸盒的巨响 |
| 段间连接 | A 到 B 仍是压盖状态；B 到 C 盒已打开、钥匙仍在；连接处雨声不突跳 |

若实际 B 结束时盒子只推到台面中间，不能在 C 直接写“林岚已经抱住”。保留符合要求的部分，定位 B 的推送、接触或时间问题，按 [结果诊断](troubleshooting.md) 修正后再核对衔接。

交付可简记：本次三个分镜分别覆盖什么、哪些提示词已写入、哪些参考已绑定、哪些结果已实际查看及采用、仍需处理的问题。没有生成时，准确报告“图片／视频提示词草稿完成，素材与模型配置待确认”，不要用上述验收表自证成片通过。
