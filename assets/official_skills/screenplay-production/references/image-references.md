# 图片资产与参考

## 先决定图片的用途

先读当前剧本、已有素材和本次镜头需要，优先复用已确认图片。身份参考、场景参考、风格参考和视频首帧解决不同问题：一张好看的气氛图未必能看清人物，一张人物设定图也未必适合直接做开场。只准备本次确实要用的图片，不为每个姿势、表情或机位另建一套资产。

图片提示词按“用途与主体 → 稳定特征 → 当前状态 → 构图与空间 → 材质和光线 → 必须保留及避免的误读”组织，省略无关项。只描述能在同一瞬间成立的画面；先做什么、再做什么，以及运镜、对白和声音变化留给视频提示词。图像模型和实际输入方式仍需查询，不假定它与视频模型相同。

需要完整成稿时读取 [图片提示词配方](image-recipes.md)：包含人物母版与派生图、状态变体、同场观察面、道具全貌与证据面、首帧合成、交接首尾帧和分镜拼图。

## 人物、场景与道具

| 参考对象 | 优先明确的内容 | 容易混淆的边界 |
|---|---|---|
| 人物 | 年龄、性别、年代与地域、社会身份；已确定的面部轮廓、体态和辨识细节；本场一套自洽的发型、服装形制、配饰与伤湿状态 | 稳定身份与临时造型分开；不为增加辨识度擅造疤痕、纹身，不把手持道具永久绑定给人物 |
| 场景 | 从哪个入口朝哪里看，门窗与固定物的相对位置，通行路线、尺度和主光来源 | 换角度不搬动门窗；天气、光照和临时摆设可以变化，变化需与本场一致；用于复用空间时宜做空场，人物走位交给镜头首帧 |
| 道具 | 轮廓、材质、相对尺度、握持或操作部位，以及开闭、完整或损坏状态 | 谁持有和是否打开属于当前状态；需要看清的文字、图案和功能面不能被构图遮住 |

## 人物形象先定事实

人物形象决定观众能否认出角色，每部作品先把主要人物做准，再进入分镜。动笔前读取作品已有的人物设定、原著外貌描写和世界观；改编作品以原著描写为准，不用演员、通行同人图或模型印象替代。

首次设计或用户反馈人物平淡、像路人、身份不符时，先读取 [人物选角与造型](character-design.md)。本附件解决参考的复用与一致性，不能代替选角和服装设计；“同一个人”只证明没有换脸，不能证明这个人适合角色。

- 年龄、性别、年代与地域是整组图的根。三者在作品资料中找不到依据时先问用户，不默认当代，也不按题材猜测。
- 其余缺口按年代、地域、阶层和职业推断，并在交付说明中标出哪些是原文明确、哪些是推断，让用户只需核对推断项。
- 服装写到形制，而不是只写品类：领型、门襟、袖口、腰线、裤型或裙长、鞋、面料与磨损。只写“衬衣”“长裤”时，模型会画成当代成衣；非当代人物还要写明不出现的当代特征，例如修身剪裁、敞领、卷袖、运动鞋。
- 面部写能画出来的特征：脸型、眉眼形状与间距、鼻梁、嘴型、肤色、发际、发质与长短。“有书卷气”“五官普通”不能约束长相，会退回模型默认的模特脸；气质改写成表情、体态和姿势。
- 图片正文只写画面内容。“本集”“母版”“此图只规定身份”这类制片用语和流程说明对图像模型没有画面含义，放在交付说明里。

## 人物参考的固定格式

制片中的人物参考统一使用一张横向组合图，作为人物身份与造型母版：

- 左侧是一幅放大的正面头肩肖像，面部细节清晰可辨。
- 右侧从左到右依次是正面、严格侧面、背面全身图，三个人形等高、脚底对齐，头顶和鞋底完整入画；背面视图的头和身体都背向镜头。
- 四个视图表现同一个角色、同一年龄、同一套发型与服装，体型、配色、配饰和衣物状态一致；一名角色一张图，不混入候选脸或其他角色。
- 使用统一的干净浅色背景与清晰柔光，视图互不遮挡；不排成四宫格，不添加姓名、标签、色卡、文字或装饰边框。人物画风沿用项目设置，不照搬示例人物的时代、服装或性别。

这是必备的人物参考格式，不是可选审核板。按「剧本工具使用规范」查询已有素材，并加载「媒体处理与剪辑」的文件读取附件实际查看图片，核对布局、角色身份与本次造型，不仅凭文件名、提示词、资产名称或生成成功状态判断。当前上下文中已看过且未变更的图片无需重复读取。确认可复用后沿用原资产引用，不重新生成或另建重复资产；无法查看时说明尚未核验，不默认合格，也不自动重生成。

根据实际图片选择处理方式：

| 已有素材 | 处理方式 |
|---|---|
| 符合上述格式，且身份、画风和造型符合本次剧情 | 直接复用，不重新生成 |
| 已有头像、正面全身图或分开的多角度图 | 保留已有脸和造型，只补缺失视图或整理成组合图；视图已齐全时不重画 |
| 只有角色设定，没有可用图片 | 根据设定制作组合图，不强制经过单幅选角 |
| 已有角色但缺少三视图，形象仍待确定或用户想换形象 | 可以询问是否先做一张正面图选角；用户选择后才增加这一步 |

生成、补图和替换仍以本次授权为准；只讨论或改提示词时报告缺口，不自动制作图片。选角图只是可选中间稿，不能替代完整参考。完整提示词见 [图片提示词配方](image-recipes.md)。

验收时逐一检查肖像、正面、侧面、背面是否齐全，是否同脸同造型、全身未裁切；少一个视图或只交正面图都不能标为参考准备完成。临时状态需写清从哪场开始、持续到哪里，并在各视图中保持一致，避免雨后湿衣在下一镜无故变干。

视频输入中明确这张图展示的是同一角色的不同视角，借用外貌与造型，成片不展示整张组合图，也不复制出四个人。身份参考不等于视频首帧；首帧另按镜头构图制作。若目标模型或渠道限制使完整组合图无法直接输入，说明具体限制并与用户确定输入方式，不自行退回单幅正面参考或省掉三视图资产。

## 风格参考

风格参考提炼可见选择：主光方向与软硬、明暗反差、主次色、材质、线条或颗粒，而非只搬“悬疑感”“治愈感”等标签。例如借鉴冷调楼梯间时，可提取青灰环境光、侧后方亮区与湿地反光；借鉴自然光室内时，可提取窗边柔光、较低反差和木材质感。参考中的雨衣人物、建筑布局或陈设不因此成为本剧事实。项目已有风格时沿用其视觉方向，按场景调整实际光源，不给每张图套同一灯光。

## 让参考各司其职

写清每张真实参考允许继承的内容和不能带入的内容。身份图可控制面貌和体态，场景图可控制空间，风格图可控制色光与材质；不要让风格图中的陌生人物、服装或标牌混进本剧。图内有多人或多个物件时，用位置及可见特征明确目标，不能默认选择居中者。引用和绑定按「剧本工具使用规范」执行。

按本镜画面实际会出现的内容选择参考，不按片段所属场次套用固定组合。码头场次的镜头里出现渡船、门外镜头里看到马车或宅门时，这些会入画的大件也需要已确认的依据；漏掉时模型会在每段各画一个不同版本。反过来，本镜看不见的人物和物件不必送入。

参考之间有冲突时先核对当前剧本状态和各自用途。例如人物设定图是干衣，而本场已淋雨，可保留身份并使用本场湿衣状态；不能让两张图同时控制同一套互斥造型。观察不到图片时说明依据来自用户描述或仍待检查，不声称已比对。

道具、招牌和屏幕上的字按剧情需要选择准确可读、仅保留不可读图形、空白或后期添加。需要可读时写明原文和位置，不同时全局要求“禁止文字”；采用后期方案时保留承载区域，并把确切文字及合成工作放在交付说明中。依赖文字的剧情信息须在最终画面可见，不能把空白图当作已经交付证据。

输入参考本身也要检查编号、字幕、标牌和其他无关字形。发现与目标冲突的内容时，在授权范围内裁切、清理或更换参考；仅在 prompt 中加“不要文字”不能证明这些内容已去除。

## 首尾帧与分镜拼图

首帧落实该镜起点，尾帧落实已确定终点；尾帧不能另创一个不同的持物、位置或人物状态。每张图分别核对人物朝向、视线、手位、道具状态和光向，不能把动作结束后才出现的结果提前画进首帧。是否需要尾帧由本次生成方式决定，不为凑齐而制作。

如果既需要人物／场景／道具参考，又需要原生首帧或首尾帧约束，先用这些参考合成正式关键帧，检查人物身份、服装状态、持物、空间关系与构图，再将确认后的单张画面送入视频模型。正式帧应是干净的实际取景，不把人物设定组合图、九宫格拼图或占位示意直接当作首帧。已有准确画面可以直接复用，不为每段额外生成图片。绑定后的实际发送角色与边界能力按 [模型能力](model-capabilities.md) 核对。

复杂多镜头可用分镜拼图先比较构图和顺序。每格按最终视频画幅安排主体，整张拼图的画幅不等于单格画幅；每格呈现一个可冻结的时刻，动作过程与时长在对应 Shot 中表达。先核对实际图片里的空间和人物，再作为参考，文字说明正确不能抵消图中站位错误。

拼图是审核或顺序参考，不直接当视频首帧。需要首帧时提取或重作相应单格，去掉审核用编号、边框和注释；需要把整张图用于参考时，先确认模型支持相应输入，说明只借镜头顺序与构图，画面不展示整张网格。不能据此保证模型逐格切镜，仍需核对时长和实际结果。

## 局部修改与交接

局部改图说明“目标区域 → 可见变化 → 保持项”，交付说明再列出受影响的片段。例如用户要求右袖淋湿时，可以写：

> 仅让人物右袖肘部以下呈浸湿后的深色，布料贴近手臂，不增加破损。保留面貌、体型、衣服剪裁、左袖干燥状态、手持物、构图及原有光向。

原图和目标区域须能从实际输入确认。这是修改意图，不是已经完成改图；更换参考后，检查引用它的后续片段是否仍与剧情状态一致。

采用图片前观察身份、造型、空间、道具和文字是否符合用途；有明显漂移的图先修正，不继续作为基准传播。多场同时换脸时先查共享人物图及其绑定；只有一场异常时先查本场输入和提示词。仅写完图片提示词时，报告“待生成／待检查”，不宣称图片已可用。
