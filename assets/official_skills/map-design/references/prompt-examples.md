# 地图内容提示词示例

以下地名均为演示。只在实际地点资料及用户授权支持时使用对应关系，提交前用 Read 返回的真实地名和 ID 替换；不能把示例世界自动写入用户作品。示例展示不同空间问题，不是题材清单；未列出的题材和混合题材同样适用。

画风单独传递，下面的 prompt 不含具体画风。API 参数写在 `options` 中，不能靠 prompt 中的“高清”代替 `quality`。

使用任一示例前，按 `cartography.md` 的“按小说类型推荐画风”给出适合本作的建议，再选择内置或自定义参数。例子附带的风格只是该用途的可能选择，不能因复制了内容示例就覆盖用户审美。标题与图例结构不因推荐画风而重排。

## 通用提示词结构

按实际任务填写以下段落，省略不适用的模块；段名用于组织指令，不要求它们成为画面文字。提交前须替换全部占位内容，最终仍提交一个完整 prompt 字符串，不向 `Run map draft` 增加标题或图例字段。

```text
用途与版面：绘制[目标范围及用途]，16:9 横版。[页式／侧栏／图内题签]布局，主图是画面主体，标题、图例与注记有各自留白，文字不贴边。
标题：顶部居中写“[确切标题]”。[必要时，在下方写确切副标题；否则不画副标题。]
主图：[视角与方向]；[整体空间骨架]；[真实地名及相对位置]；[必须成立的通路、边界与限制]。
标签：[必画名称、层级和放置要求]；逐字准确，避免重叠；标题和图例不冒充地理对象。
图例：[位置]，仅列[符号样本及含义逐项说明]；主图与图例的形状、线型、颜色和方向完全一致。[全用直接标注、不需要图例时省略本段并明确不画图例框。]
辅助信息：[已知方向标记]；[经确认的比例尺／非等比例说明]；[必要附图的名称、范围和对应关系]。不用的要素不画。
保留与排除：[本次不可改变的内容]；画面文字只包含本次列出的标题、地名、图例与注记，不增加口号、伪文字或无依据的数值。
参考图：[有参考图时，按实际附图状态明确各自职责]。
```

这是一份构图规格，不是需要用户逐项填的表单。能从地点资料和上下文推导的直接填写；影响世界事实的缺口再询问。

## 完整示例：一处场所的平面图

前提：目标地点“旧馆”及其门厅、西厅、东厅、中庭已存在，楼层和下面的连接关系已确认。它可用于不同题材；不自动增加密室、犯罪现场、怪物或解谜机关。

```text
绘制旧馆一层的阅读用平面地图，16:9 横版，正上方俯视，使用上标题、中主图、下辅助信息的页式布局。四周保留安全留白；主图占画面绝大部分，不能排成海报或应用界面。

标题区在顶部居中，只写“旧馆一层平面图”，仅出现一次。无副标题、年代或署名。

主图外轮廓接近长方形。“门厅”在画面下部中央，“西厅”在左侧，“东厅”在右侧，“中庭”在上部中央。主入口位于门厅下侧外墙。门厅分别通过西侧和东侧的门连接西厅、东厅；西厅和东厅各有一扇门通向中庭。门厅与中庭之间是完整隔墙，没有直通门；西厅与东厅之间也没有直接通道。

外墙及内墙使用连续粗线，门洞使用墙体缺口加开启弧线；主入口在门洞外增加小三角定位符号。房间大小只作排布示意，不表示真实面积。四个空间名称分别置于各自内部的空白处，名称逐字正确，各出现一次；不被墙线切割。

底部左侧排列紧凑图例，标题“图例”。只有三项：小三角加门洞样本对应“出入口”；墙体缺口加开启弧线对应“可通行门”；连续粗线对应“封闭墙体”。样本与主图完全一致，每项样本在左、说明在右，条目之间留空，不列房间名称。

底部右侧只写“非等比例示意”。方向未校准，不画指北针或东西南北；不画数字比例尺、尺寸标注、附图或装饰边框。

画面只出现上述标题、四个空间名称、图例标题与三条说明，以及尺度注记。文字清楚，互不遮挡，未列出的地名、说明和装饰性文字均不添加。不得增加门厅至中庭的捷径或其他楼层。
```

可用 `style: "atlas"`、`resolution: "2k"`。这是完整内容示例；其他风格通过独立参数选择。

## 空间内容片段的用法

以下展示不同空间约束的写法，不是可以省略版面的完整成图指令。新图使用这些片段时，按通用结构补齐具体标题、图例条目、辅助要素与位置；只借用适用部分。局部编辑则保留当前版式。

## 不连续空间：浮陆之间的阻隔

前提：设定确认三块浮陆、不可直接横渡的裂隙，以及唯一连桥与单向界门；所有具名地点已在目标子树内。

```text
绘制玄幻世界的浮陆通行示意图，16:9 横版，以俯视轮廓表现浮陆，少量侧面高度帮助辨认悬空结构，不遮住道路和地名。画面布局用于理解连接关系，不表示实际距离。

“玄衡陆”位于左侧，“赤霄陆”位于右上，“幽泉陆”位于右下。三陆之间是无法直接横渡的虚空裂隙，各自有完整独立轮廓，不能以连续山地或海岸连接。

“悬天桥”是玄衡陆与赤霄陆之间唯一的实体连接，两端准确接上陆缘。赤霄陆上的“归墟门”通向幽泉陆，用带单向箭头的虚线连接入口与落点；这是跨空间通路，不画实体桥。玄衡陆与幽泉陆之间没有直接通路，不能为了构图平衡补第三条边。

三块浮陆名称大于桥与门的名称，所有名称逐字准确、各出现一次。小图例只解释实体桥与单向界门。保留裂隙的空白和通路端点，避免巨型神兽、人物或云雾遮住关系，不添加新地名与数字比例尺。
```

宏阔厚重的作品可推荐 `realistic` 或自定义设色舆图；清雅气质可推荐 `inkmap`，具体按本作选择。不可凭“玄幻”自行追加更多界域和通路。

## 主图与异空间附图：宗门与独立洞天

前提：本图允许展示秘境入口，且灵脉、禁飞区与入口位置已经确认。

```text
绘制“青岚宗”及其所辖山域地图，16:9 横版，主图为上北下南的山域俯视图，右下角另设一个边界清晰的洞天示意小图。

“山门”在南部谷口，“青岚坊”在山门以南，“主峰”在北部。“地脉”由主峰下方延伸至西侧的“灵矿”，以独立细线符号表示地下灵气走向，不画成水面或交通道路。山路从青岚坊经山门通向主峰。“禁飞谷”在主峰东侧，保留其边界，不画横穿谷地的御空捷径。

“问玄门”位于主峰西侧，是“问玄洞天”的入口。小图表现洞天为独立空间，用带说明的连接线指向主图的问玄门；小图位置只为排版，不表示洞天就在主峰东南，也不暗示洞天面积受入口大小限制。

主图标签标注青岚坊、山门、主峰、地脉、灵矿、禁飞谷、问玄门，小图只标注问玄洞天。地名逐字正确，线型区分山路、灵脉和洞天连接；不补充其他宗门、境界门槛或未给出的秘境开启周期。
```

清雅作品可配 `inkmap` 或自定义淡墨设色，重在宏阔宗门世界时可推荐 `woodcut` 或自定义立体舆图；只有任务重在技术式通行表达时才考虑 `atlas`。地图只展示所提供规则，不把“仙气”当作空间设计。

## 地形与流向：关隘与粮道

前提：资料已确认“开宁三年秋”的局势、所列地点与河岸关系；未确认时替换或省略年代，不虚构历史。

```text
绘制开宁三年秋“临川道”的军事地理图，16:9 横版，上北下南，重点是关隘、城镇与粮运通路。

“临川城”在中部、“北关”在北部山口、“南仓”在南部，三处都在“临江”西岸，临江自北向南流过。陆路从临川城向北抵达北关；粮运路线从南仓沿江向北到临川城，以箭头标明运输方向，再由陆路送往北关。水路位于河道上，不能画成跨山直线。

山口是进入北部的关键通道。仅按本阶段已知资料标示控制范围，不把后续战争结果加入版图；不推断军队数量、粮运规模和行军天数。文字清楚，图例区分普通道路与粮运方向，地形和城镇优先于军旗装饰。
```

可配 `woodcut`、`engraving` 或 `atlas`，不要求所有架空小说都用羊皮纸。

## 通行网络：星区跃迁

前提：设定确认五个恒星系及下述通路。节点代表恒星系，不能在同一图层混作单颗行星。

```text
绘制“远航星区”的二维航路示意图，16:9 横版，节点位置用于清楚表达可达关系，不代表真实三维坐标、光年距离或星体尺寸。

“曙光系”在左侧、“天枢系”在中央、“寒湾系”在右上、“赤砂系”在右下、“孤灯系”在下方。双向稳定航道只有曙光系—天枢系、天枢系—寒湾系、天枢系—赤砂系，以无箭头实线表示。赤砂系到孤灯系只有一条单向虫洞，用虚线和指向孤灯系的箭头表示。孤灯系没有已知返航通道。

寒湾系和赤砂系之间有封锁区，它们没有直接航道，不因画面相近而连线。线条只在恒星系节点终止；交叉但没有节点的线不代表中转站。每个恒星系用统一符号与中文名称表示，名称逐字准确且只出现一次；图例说明双向航道、单向虫洞和封锁区。

保持标签与连线清楚，不添加地球大陆轮廓、经纬网、罗盘、虚构里程、航行时间或额外星系。不要用巨大行星插画遮住节点和通路。
```

配 `atlas`，或 `style: "custom"` 加独立视觉描述。应用没有 `sci-fi` 风格枚举，也没有 `projection`、`star_system` 等地图草稿参数；表达方式写在 prompt 中。

## 世界图：先定整体关系

假设资料已确认北境、南原两个地域，以及雪关、河都、东港和清河的归属与方位：

```text
绘制小说世界的阅读地图，16:9 横版，俯视平面，上北下南。主体是一块大陆，东侧临海；展示北境与南原之间的地理关系和主要交通。

北境位于北部高地，南原位于中南部平原；东西走向的山系分隔两地，雪关是山系中段的通行缺口。不得把两个地域画成互不相连的岛屿。

“雪关”标在山口。“清河”发源于北部高地，从雪关东侧的既定峡谷向南流入南原，再转向东海岸入海。“河都”位于山系以南、清河西岸。“东港”位于入海口北岸。道路从雪关南下抵达河都，再通过河都东侧的桥通向东港；桥只跨清河一次。

“北境”“南原”作为地域名称，位于各自地域内部；城市和关口名称较小，紧邻各自符号。“清河”沿河道排布。所有指定名称逐字正确、各标注一次，标签不压在山脉密集处，不跨越疆界。

保留道路、桥梁与河岸的辨识空间。只出现指定地名，不补充国家、城市、英文副名、乱码或无依据的数字比例尺。地图主体占据主要画面，边角装饰不得遮挡海岸和文字。
```

可配 `style: "parchment"`、`resolution: "2k"`；文字精度优先时选择 `quality: "high"`，但仍需看图核对。

## 区域图：明确通路与阻隔

```text
绘制“落霞谷”的区域地图，16:9 横版，俯视，上北下南。只覆盖谷地及两侧山体，不画其他大陆或国家。

谷地沿西北至东南展开。“北隘”位于西北入口，“石镇”位于谷地中段，“南渡”位于东南出口。“溪河”由西北流向东南，石镇在西岸；主路从北隘到石镇，再沿西岸到南渡，渡口连接东西两岸。两侧高山形成连续阻隔，不新增绕过北隘的通道。

北隘、石镇、南渡的符号与名称清晰分离，河流和道路采用可辨别的线型；每个名称只出现一次。仅标上述地点和溪河，山体保持无名。文字背景少纹理，不增加旅行时间、里程和新地名。
```

## 城镇图：路径能走通

```text
绘制“石桥镇”的城镇平面地图，16:9 横版，正上方俯视，上北下南，重点表现街区、街道、城门与桥的连通关系。

“青水河”自北向南穿过城镇东部。“西门”位于西侧城墙中央，“东门”位于东侧城墙中央。“集市”位于河西的镇中心，“石桥”位于集市正东的河道上，“码头”位于石桥下游的西岸。

主街依次连接西门、集市、石桥和东门，跨河处准确落在石桥上；支路从集市通向码头。普通房屋作为无名街坊，留出连续道路，不让建筑压在街道或桥面上。不要把城门画在没有道路的封闭墙段。

标注“西门”“东门”“集市”“石桥”“码头”“青水河”，文字逐字正确并紧邻对应对象。街区与建筑按同一平面尺度表达；不画大陆山系、夸张透视建筑、人物特写、额外地名或装饰性伪文字。
```

## 当前图局部改动

用于实际已有当前图，并传 `reference_current_image: true`。名称位置等约束应来自用户要求及已确认资料；这只是编辑模式示例：

```text
image 1 是当前地图。只修正“东港”的名称位置：保留港口符号在原处，把“东港”文字移到符号北侧的空白处，避免盖住海岸线；文字逐字为“东港”，只出现一次。

保留原画幅、朝向、海岸轮廓、山系、河道、疆界、所有地点符号及其他标签的位置；不改变道路端点、不添加地点、不整体重新构图。若附有上层地图，只作为视觉风格参考，不复制其地形和地名。
```

风格沿用当前选项；不是同时提出改字、改河道、改风格和重画大陆。若用户同时要求多项更改，逐项列清，保留项排除这些明确改动。

## 子地图参考父图

在完整子地图 prompt 后追加参考职责。只有父图、且已确认会附图时：

```text
image 1 是上层地图，仅沿用它的画风、配色、线条质感和地名字体。本图按上述城镇平面关系重新构图，不沿用上层地图的陆海布局、山脉位置、疆界和地名，也不是在原图上圈出城镇。
```

有当前图和父图时改为“image 1 是当前地图，按本次编辑要求保留；image 2 是上层地图，仅作视觉风格参考”。若不知道制图师最终选择哪些参考图，不虚构附图状态，使用主指南中的条件式表述并提示用户在生成前核对。
