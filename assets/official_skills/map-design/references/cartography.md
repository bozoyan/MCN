# 小说地图的空间与视觉设计

以下是小说地图的设计启发式，不是 GPT Image 2 的确定性能力，也不是所有虚构世界都必须遵守的自然定律。已有设定优先；影响情节的新关系要作为方案说明。

## 先选择故事需要的地图

地图要支持本次创作问题：追逃需要阻隔与出口，宗门竞争需要资源与控制范围，战争需要关隘与补给，星际航行需要航路和中转。没有相关情节时不强加这些要素，不把每张地图都做成势力争霸图。

| 表达方式 | 何时适合 | 必须说清 |
|---|---|---|
| 地理平面图 | 同一片连续空间，方位、地形和距离关系影响剧情 | 朝向、范围、关键阻隔；没有尺度资料时不添加数字比例尺 |
| 界域／层级示意图 | 上下界、独立洞天、悬空层或异空间 | 分区不是连续陆地；位置表示层级还是物理高差；跨区通过什么连接 |
| 航路／通行网络图 | 传送阵、虫洞或跃迁使可达性比直线距离重要 | 节点是地点，连线是可用通路；无连线是否不可达；哪些通路单向或受限 |
| 局部详图 | 宗门驻地、城池、空间站或一片具体战区 | 从总图继承的入口和相对关系；本层展示哪些内部结构 |

主图只承担一种主要阅读任务。需要同时呈现地理与异空间时，可用一个有明确边界的小幅示意图辅助；不把大陆、宗门建筑和星系按同一尺度堆在一起。这里的“图层”是构图层次，最终仍是一张图片，不承诺可切换图层、实时缩放标签或交互星球。

## 按空间特征适配，不按题材分桶

题材只提供语境，不决定地图结构。对任何小说先判断以下维度；同一作品可以同时使用几种，已知信息直接复用，不把表格变成必问问卷。

| 维度 | 设计判断 | 常见误画 |
|---|---|---|
| 范围和空间载体 | 故事发生在世界、区域、街区、设施、房间，还是不连续空间？ | 所有请求都从一块大陆开始；室内地图画满山脉 |
| 连续性和层级 | 地表是否连续，是否有楼层、地下层、独立空间或循环结构？ | 将上下楼层当作南北；附图的位置被误解为物理方位 |
| 移动规则 | 步行、道路、航行、楼梯、门禁或特殊通道；是否单向、定时或受限？ | 几何邻近自动变成可达；漏掉连接层级的入口 |
| 控制与状态 | 归属、使用权、争夺区、危险区是否相关，是否随时间变化？ | 所有影响范围都画成国家边界；不同时期状态混在一起 |
| 知情范围 | 作者掌握的事实、人物已知内容、传闻和未知区域如何区别？ | 把未知画成空无一物；从图例泄露隐藏出口或身份 |
| 图的读者与媒介 | 作者工作图、读者附图、书中人物绘制的实物图，分别需要多精确、多完整？ | 每种地图都做成全知精密图册；为“古旧”牺牲基本可读性 |

例如城市日常可能重在街区与活动范围，密闭场所中的调查可能重在门窗与视线，灾后生存可能重在可通行道路与补给，跨空间故事可能重在入口与连接。它们只是如何使用上述维度的例子，未列出的题材照样适用，不固定添加势力、危险区或超自然元素。

宗门／势力可以跨地域拥有据点，影响范围也可重叠，不必给每方分配一块完全排他的封闭国土。若用户关心的是强弱或归属而非空间位置，可建议另用关系图；既已请求地图时保留地图任务，只减少与空间无关的信息。

所有地图都要区分“近”与“可达”：两处相邻也可能隔着锁门、禁制或断路，远处可能有直达通道。条件明确时用简短标签说明单向、封锁、定期开启或权限限制；没有给出条件时不要编造门槛、消耗或行程时间。表示层级高低的上下摆位，不自动解释为上北下南。

子图涉及图外通路时，保留本图侧的出口及已有去向说明，不扩建范围外的地点。星区、洞天等概念按现有地点 schema 可表达的类型和描述记录；不发明 `planet`、`realm` 等工具枚举，也不为适应地点树伪造物理包含关系。无法准确表达时说明缺口。

## 图面结构规范

这是本项目为小说图片地图制定的默认规范；要素的必要性取决于用途。默认位置与留白是构图建议，不是外部制图标准规定的坐标，也不保证图像模型逐像素执行。

### 默认版式与取舍

- **页式地图**：顶部放标题及必要副标题，中间主图，下方左侧为图例、右侧为尺度或简短注记。主图应占绝大部分画面。外缘留出约 3%–5% 的安全距离作为起点，不能让边框切到文字。
- **侧栏地图**：主图横向空间允许、图例较多或需要附图时，将辅助信息统一放到一侧，标题仍居上。不要把每条说明做成漂浮卡片遮在地图中间。
- **图内题签**：完整海岸轮廓或特殊外形需要大块连续画面时，可以将标题、图例放入海面等真实空白区域。不能为了腾空放题签而挪动已确定的城市、海岸或道路。
- **局部编辑**：只改地名或通路时，不为了补齐规范重排整张图。需要修订版式时再整体规划。

先确认要展示的文字与图例数量，再分配留白。空间不足先缩减无用说明和装饰、调整布局；不要缩小必读文字到不可辨认，也不要删除用户要求的地点。

### 标题与副标题

标题回答“这是什么地方的什么图”。优先使用用户给定图名；否则以目标地点正式名为核心，追加确有必要的范围／用途。可采用「目标名＋全图／地区图／平面图／路线图／通行示意图」等自然写法，不机械追加所有后缀。例如「澄湾地区图」「旧馆一层平面图」；只展示局部时不能写“世界全图”。

标题默认一行、居中、最大字号；长名可合理分行，不能截断正式地名。标题只在题签出现一次，不再把同一标题写成主图中的巨大地域标签。子图标题用子地点本名，有重名歧义时才在副标题补父级名称。

副标题放标题下方，明显小一档。只放本图必要的时代、楼层、故事阶段或认知范围；未给出时省略。题签是承载标题的外框，图例是解释符号的内容，不能把两者混为一张装饰标签。装饰性字体可以用于标题，地点与图例仍优先用清楚的中文字体。

### 图例是主图的符号说明

写 prompt 前先列出本图实际用到的对应关系，每项包含符号样本、含义和是否需要方向：点符号表示地点类别，线样本表示通路或边界，色块／纹理表示范围或状态。文字应直接解释含义，例如“可通行道路”“封闭区域”，不用“图层一”或技术参数名。

- 主图与图例使用完全相同的图形、填色、描边、线型和箭头方向；不能主图虚线、图例实线，同色异义或异色同义。
- 每种非直观符号和有语义的线型／颜色都应有解释；图例每项也须在主图中真实出现。直接地名标注不需要在图例重复列成一张地名清单。
- 按读图顺序分组：地点 → 通路 → 边界／状态。条目少时底部横排，较多时侧栏纵排；一般先尝试 3–6 项，但不为凑数量新增类别，也不因超过数量删除必要解释。
- 图例里的线段要足以看出虚实和箭头，面符号样本要看得出纹理。样本与说明成对排列，行距一致；文字不能贴住样本，更不能盖在样本上。
- 不用一套红绿颜色单独区分类别；配合形状、线型或文字。没有数量资料时，不用渐变或粗细图例暗示人口、实力或流量。
- “未知”与“没有”分别表达；视角不允许披露的符号、地点类型也不能借图例提前透露。

有少量直观地点且均直接标注、没有其他编码时，可以省略图例。不要生成空的“图例”框，也不要为追求完整额外画山、桥或传送门。

### 方向、尺度、附图和注记

| 要素 | 加入条件 | 内容与边界 |
|---|---|---|
| 指北标／方向说明 | 地理方向影响阅读，且方向已确定 | 放主图空白角落，小而清晰；中文地图可只标“北”。非地理层级不套罗盘，楼层顺序另作说明 |
| 比例尺 | 有可靠距离、单位及统一比例依据 | 刻度与画面距离须一致；附图另标自身尺度。图像模型出图后仍须核验，不能声称可用于精密量测 |
| 尺度注记 | 拓扑、跨尺度或相对位置示意可能被误认为精确地图 | 写“非等比例示意”或明确的适用说明；未知距离时不编“0–100 公里” |
| 定位附图 | 读者需要知道主图在上级范围中的位置 | 用明确范围框或高亮区对应主图，有简短标题；不能虚构未知的上级轮廓 |
| 放大附图 | 关键密集区域在主图中难读 | 标出被放大范围，名称与连接保持一致；单独说明不同尺度，不能让人误以为新增另一座城 |
| 分层／异空间附图 | 同一平面无法准确表达不同层级或独立空间 | 分开图框，以入口或连接点对应；写清空间名／层级，图框之间的留白不是实际距离 |
| 时间／视角注记 | 状态变化或知情范围影响解读 | 使用已确认的阶段信息，简短呈现。不存在的日期、署名、测绘机构、版权和资料来源不要编入图面 |

装饰边框可帮助收束版面，但不必每张图都用卷轴。小说地图无需自动添加 GIS 坐标系、投影编号或学术引用；如实际使用需署名的外部地图素材，按素材要求另行处理，不伪造来源。

### 系列地图的一致性

同一作品的父子图、同类场所图或不同时间版本，保持标题命名、字体层级、符号含义、势力配色及图例组织一致；图幅尺度改变时可减少细节，不能悄悄改变符号意思。真实状态发生变化时更新相应主图与图例，并按需要标注阶段。

## 让世界观有可辨认的形状

从已确认设定提炼一个主要空间特征，例如环绕裂隙的浮陆、沿灵脉展开的宗门、被关隘控制的河谷或围绕跃迁枢纽的星区。它应改变区域轮廓、通行结构或节点布局；不能只靠紫色云雾、金色符文和“宏大”字样表达题材。

先安排空间与阻隔，再安排地点／势力，随后画通路，最后放标签。底纹承托信息，核心入口和地名留在清晰位置。用线型和符号区分地形边界、势力影响与特殊通路；颜色辅助，不用同一种虚线同时表示疆界、御空航线和未探索路线。

地名标签可以有细描边或干净底色，以免淹没在星云、山纹中；效果随背景选择，不机械规定所有题材都用白字黑边。图例只解释本图实际使用的符号。线宽、节点大小只有被明确赋予含义时才表示流量、力量或人口，否则仅用于阅读层级。

## 随尺度取舍

| 尺度 | 必须读得清 | 应简化的内容 |
|---|---|---|
| 世界 | 大陆、海域、主要地域、跨区通道、少量关键城市 | 街道、单栋建筑、密集小村，不把每个子孙地点都画成等大图标 |
| 区域 | 地形阻隔、城镇、河流、道路、关口和渡口 | 远方大陆、宏大装饰、与区域通行无关的细节 |
| 城镇 | 城墙与入口、街区、主街、桥、港口、关键建筑及可达关系 | 大陆式山脉图标、巨型城堡遮住街道、同时混用平面与透视尺度 |

世界图可以用象征图标表达城镇；城镇图优先俯视平面以便读路。用户要求等距插画时可采用，但保留道路连续与建筑间距，不宣称精确测绘。

上表适用于地表地图。界域图按空间层级、星图按星区／恒星系／行星／设施层级取舍，不把星区机械套为“大洲”、空间站套为“古代城池”。

## 地理骨架服务情节

以下用于采用自然地形的空间；已设定的逆流天河、无重力浮陆等按其世界规则表达，不以现实常识“修正”。

- 山脉组织成有走向的山系，关隘对应可穿越处，避免为填空把孤立山峰均匀撒满地图。
- 通常让河流从高地走向低地，支流汇入干流并通向海或内流湖；河口三角洲、分汊河或魔法水系可以例外，须与设定相符。不要让普通河道无说明地翻越分水岭。
- 城镇的选址可以由河口、港湾、桥头、绿洲、矿产或交通交汇解释；既有故事若刻意设置偏远孤城，保留其特殊性。
- 道路连接实际目的地，遇山脉经过山口，跨河落实桥梁或渡口。不同势力接壤不等于道路自动畅通，封锁、荒原和禁区按设定表达。
- 疆界可借地形，也可以是人为边界；不强制所有国家都由河山封闭，不把行政边界画成水系。
- 不从世界名称推断国家数量，不擅自增加势力；“七洲”之类字样只有被地点资料或用户明确确认为数量时才作为约束。
- 没有距离资料时采用相对关系；不编造公里数、比例尺或精确旅行时间。真实地点需要真实地理资料时先说明资料缺口，不能把模型常识当测绘依据。

## 可读性优先于纹理密度

让最重要的对象先被看见：疆域范围、通行网络、核心地名；地形纹理退到背景。层次由字号、线粗、明暗及留白共同表达，不只靠颜色。

地域名落在自己的区域内；城市名靠近城市符号；河名沿河道，避免压住交汇口。不同区域标签不能被山脉或花纹切断。近邻地名先错位排布、缩减装饰、保留干净底色，仍拥挤时提出子地图方案，不悄悄省略必画名称。

城市符号应比地域标签小，但与城市文字关系明确；首都、港口、遗迹等采用少量一致的符号类别。需要图例时只解释实际出现的符号，避免图例本身占据主体。

装饰边框与海兽等插画仅在用户需求支持时加入；标题按图面结构规范处理，不以巨大卷轴包装。方向与尺度按实际空间决定。颜色可区分势力，边界线和文字也必须能独立区分它们。

## 按小说类型推荐画风

先回答“怎样的视觉语言符合这部作品”，再决定 `style`。推荐须具体到地形和地点如何画、怎样设色、采用什么媒介与字体，不能只说“玄幻风”“高级感”。下面是创作建议，不是类型限制或模型效果保证；类型相同而气质不同，推荐应不同。

### 类型与视觉方向

| 小说类型／作品气质 | 可考虑的内置风格 | 需要更明确表现时的自定义方向 |
|---|---|---|
| 东方玄幻、修真：宏阔、厚重、探索大世界 | `realistic` 写实地形、`woodcut` 古籍插图 | 东方设色舆图，立体山脉与清楚的地貌高差，古建微缩地标，矿物青绿与赭石、冷暖地域对比；细节丰富且地名易读 |
| 仙侠、修真：空灵、清雅、山水意境 | `inkmap` 水墨舆图、`watercolor` 柔和水彩绘本 | 宣纸墨线与淡青绿设色、山体皴法、薄雾与疏密变化；雾停留在地形间隙，不吞没地点和通路 |
| 武侠、江湖游历 | `inkmap` 水墨舆图、`woodcut` 古籍插图 | 古代行旅舆图，山川笔意、城镇关隘小景，墨色与少量设色，沉稳或洒脱随作品语气调整 |
| 历史、架空政治、战争 | `woodcut` 古籍插图、`engraving` 版画线描；参谋用途可用 `atlas` | 与时代相符的疆域舆图或军用测绘图，城防与地形轮廓清楚，纸色和笔触有年代感；气势来自地貌与城池，不靠额外军队插画 |
| 西式奇幻、史诗、冒险 | `parchment` 手绘羊皮纸、`engraving` 版画线描 | 羊皮纸墨线、山形排线、城堡与港湾小景，宝石色或沉郁色调随作品气质变化；做旧不能遮字 |
| 科幻：硬科幻、太空探索、技术理性 | `atlas` 清晰现代图册；行星地表可用 `realistic` | 航图／科学制图语汇，精确线条、清晰节点和字体，明暗底色按使用场景选择；不自动生成 HUD 数字和仪表盘 |
| 科幻：太空歌剧、壮阔浪漫 | `realistic` 写实地形或 `custom` | 深空绘景与发光航路、富有层次的星云及星体微缩意象；控制光晕，保留网络关系，节点大小不冒充真实天体尺度 |
| 赛博朋克、近未来都市 | `atlas` 清晰现代图册或 `custom` | 城市测绘底图、建筑体块与分层高架的图示质感，深色底加少量霓虹强调；不能把地图变成不可读的 UI 截图 |
| 末世、生存、废土 | `realistic` 写实地形、`engraving` 版画线描或 `custom` | 野外勘察图、磨损纸面或废旧航测图的质感，灰土色与有限警示色；磨损留在边缘，不自行增加污染区、废墟或封锁线 |
| 悬疑、推理、谍战 | `atlas` 清晰现代图册、`engraving` 版画线描 | 档案式城市图、建筑测绘图或简洁调查图，准确线条与清楚空间分隔；不以装饰红线虚构线索关系 |
| 恐怖、诡秘、志怪 | `engraving` 版画线描、`inkmap` 水墨舆图或 `custom` | 阴冷版画、旧档案或幽暗设色舆图，压低局部色彩、强化轮廓与留白；阴影表达氛围，不将既有安全场所改成危险设定 |
| 都市、现实、校园、言情、生活流 | `atlas` 清晰现代图册；温暖叙事可用 `watercolor` | 街区手绘、建筑速写或温暖水彩，强调熟悉场所的辨识度；是否轻盈或冷峻看作品气质，不由题材标签决定 |
| 童话、轻幻想、治愈、轻松冒险 | `watercolor` 柔和水彩绘本或 `custom` | 绘本设色、柔和形体、亲切的小景地标；色彩可以鲜明，不默认低饱和，也不强制幼儿化或卡通化 |

表中方向可以组合，但只保留一个主导媒介。例如“都市修真”可用都市建筑速写承载淡墨神秘气氛；“科幻恐怖”可用冷静技术制图配合幽暗底色。不要把羊皮纸、霓虹 HUD、油画、木刻同时堆入一个描述。未列出的题材按时代、作品气质和地图用途推导，不强行归入已有行。

### 按本作与用途收敛建议

1. **先用已知审美依据。** 用户给出的参考图和明确偏好优先于题材惯例；从中提取地形塑造、建筑表现、用色、媒介和字体，不能声称知道参考图原本用了哪个预设。参考图不是文字设定来源，不复制其新地名或地域。
2. **再看气质。** 宏阔世界可以有丰富山体细节和地域色彩；空灵作品可用墨色疏密；冷硬作品可用测绘语言。清晰可读主要靠文字位置、局部对比和层级，不要求整个世界少纹理、无建筑、只剩圆点。
3. **按地图任务调节。** 世界总览保留地貌辨识和作品氛围；精确室内平面和追踪路线更重视几何与连接。不能仅因同属一部修真小说，就把所有室内图画成山水；也不能因需要路线清楚，就将世界总览默认做成旅游导览。
4. **保持系列一致。** 父图和子图沿用媒介、配色及字体，细节随尺度改变；用户明确要求改风格时再提出新的系列方向。风格改变不要求重排标题、图例或更换故事地点。
5. **给出可落地建议。** 默认推荐一个方案并解释依据。只有存在显著不同且都合理的审美方向时，补充一个备选；用户授权你决定时直接采用，不让风格建议变成反复确认流程。

### 内置与自定义的选择

代码内置的风格词分别是：`parchment`＝手绘羊皮纸，`inkmap`＝水墨舆图，`engraving`＝版画线描，`realistic`＝写实地形，`woodcut`＝古籍插图，`watercolor`＝柔和水彩绘本，`atlas`＝清晰现代图册。它们是短语，没有隐藏的详细模板；更长的明确视觉要求用 `style: "custom"` 和 `custom_style` 表达，不能发明新的 style ID。

自定义描述按需组成：**主导媒介＋地形／建筑的画法＋底色与色盘＋线条／光影＋字体＋局部可读性要求**。它可以改变已有山脉或城池的画法，不能引入新地点、变动位置、重排版面，或规定未经设定支持的建筑功能。

宏阔东方世界，推荐理由示例：“这部作品重在跨地域探索，建议设色立体舆图；山体高差和古建地标能体现世界的体量，同时保留现有标题、图例和道路层级。”可提交的风格参数：

```json
{
  "style": "custom",
  "custom_style": "东方古典设色舆图，古纸底色，工笔墨线结合细腻地形浮雕感；已有山体呈现清楚高差与山势层次，已有城池和关隘采用可辨认的古建微缩图示。矿物青绿、赭石与冷灰协调设色，植被和岩层纹理丰富但层级有序。标题可有端正书法韵味，地名与图例使用清晰中文字体；只在文字周围减弱纹理，通路保持清楚，避免厚重阴影遮住边界。"
}
```

同为修真但气质清雅时，建议应随之变化：

```json
{
  "style": "custom",
  "custom_style": "清雅山水舆图，宣纸底色，细墨轮廓与淡青绿设色；以疏密皴笔表现已有山体，已有建筑采用精细小景图示，薄雾只停留在空隙。画面明净而有山势层次，地名和图例文字清楚，道路不断于雾中；避免浓墨覆盖标签或将整幅地图处理成无空间关系的山水画。"
}
```

这两段是条件化示例，不能作为所有小说的默认画风。内容 prompt 如果已要求纯圆点、绝对平面或极少细节，不可同时提交强调微缩建筑与地形塑造的自定义风格；先按用户目标协调表现要求，保留信息和地理关系。

## 看成图时检查什么

先看完整图面能否回答“画的是哪里、主图在哪、符号怎么读”：标题和范围相符，图例与主图逐项对应，方向与尺度有效，辅助内容没有压住主体。副标题、附图与图例不能泄露当前视角下的秘密。以实际阅读大小检查文字，不能只在放大后认为可读。

先核对地名逐字正确、必画对象无缺失和重复，再看相对方位、包含关系、路线端点、桥与河的相交关系。最后看层级、色彩、纹理和风格一致性。缩小看信息主次，放大看标签与道路接头。

跨界／星区图再检查：普通通路与特殊通路是否可区分，单向箭头是否正确，交叉线是否被误画成节点，洞天是否被误画成相邻地块，禁区是否出现未经授权的捷径。涉及时间或秘密信息时核对本图对应阶段与知情范围。

“画得漂亮”不能抵消城市在错误的河岸、城门没有路或疆域归属错误。仅收到 prompt 或草稿提交结果时，上述视觉检查应明确记为未验证。
