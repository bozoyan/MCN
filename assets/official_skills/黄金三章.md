# 黄金三章

网文黄金三章不是"三章之内把事讲清楚"，而是"三章之内让读者对主角产生牵挂"。

堆冲突不如堆情绪。冲突让人紧张，情绪让人放不下。

读者要在前三屏知道：主角是谁、他缺什么、他为什么不该落到这个处境、下一步有什么值得等。

## 开篇 300 字

- 前 200 字必须让主角出现，并让他做出第一个可见行动。
- 前 300 字必须给出反常、落差、危险、利益或误会中的至少一种钩子。
- 第一章场景不超过 2 个，互动人物不超过 3 个。
- 800 字内触发核心冲突；不要先铺世界观、履历、体系名词。
- 开头段落优先写具体事：谁在场、正在发生什么、主角被迫面对什么。

## 第一章：展现落差

### 原理

新手常犯的错误：主角第一章被追杀/被退婚/被扔进绝境，冲突够猛，读者还是划走。

原因很简单：读者还不认识主角。一个陌生人被刀架在脖子上，没人关心。

真正有效的第一章不是让危险发生，而是让**落差被看见**：主角曾经站在哪里、现在跌到了哪里。落差越大，情绪越重。

### 落差公式

```
读者对主角的同情 = f(过去的地位 − 现在的处境, 地位的合法性)
```

- 过去的地位必须有"合法性"：读者得认可主角配得上那个地位（天赋、家世、努力都可以）
- 现在的处境必须是"不该如此"：不是因为主角活该
- 两者差距越大，读者越急着想看主角翻身

### 落差三要素

1. **锚点**：主角坠落前的最高光时刻（一个具体画面：万人敬仰、家族第一、天才之名）
2. **现状**：坠落后的最低谷（一个具体画面：被嘲笑、被无视、能力尽失）
3. **对比触发器**：让锚点和现状在同一个场景里正面碰撞

### 三种落差模式

| 模式 | 适用类型 | 经典案例 |
|------|----------|----------|
| 天赋坠落 | 玄幻/仙侠 | 萧炎从天才变废物，测试现场被嘲笑 |
| 身份颠覆 | 都市/历史 | 顶级特工变成普通上班族，被小混混欺负 |
| 认知反转 | 悬疑/系统流 | 主角以为自己是普通人，突然发现隐藏身份 |

### 关键数据

- 800字内必须触发核心冲突（起点编辑通用标准）
- 前300字最后一句必须是戏剧性反转
- 第一章场景 ≤ 2 个，互动人物 ≤ 3 个
- 前200字必须出现主角

### 案例拆解

**《斗破苍穹》第一章**
萧炎参加家族斗之力测试。曾经"闻名乌坦城的天才"，被所有人嘲笑是废物。
天蚕土豆没有一上来就写退婚，他先让读者看到从天才到废物的坠落。
读者不是因为"纳兰嫣然退婚了"而生气，而是因为"萧炎已经很惨了你们还要踩他"，才想让萧炎打脸所有人。
情绪到位了，事件才响得起来。

**《诡秘之主》第一章**
克莱恩醒来，发现自己在一场自杀仪式中幸存。
乌贼没有急于展示非凡世界，而是通过克莱恩的日常细节，他如何小心应对值夜者的盘问、如何掩盖记忆冲突，让读者看到"一个普通人在陌生且危险的世界求生"。
落差不在于地位的改变，而在于认知的颠覆：他以为自己是穿越者，实际上踏入了一个比死亡更可怕的深渊。

## 第二章：特权信息

### 原理

第二章最常见的错误是把主角写得越惨越好。反派越坏读者越气，但只够撑一章。

第二章真正的任务不是拉仇恨，而是给出"读者知道但其他人不知道的信息"。这种信息差会产生"上帝视角"的快感。读者手里捏着一把枪，知道下一幕一定会响，但不知道什么时候响，这种等待比任何哭喊都让人焦灼。

### 四种特权信息

1. **身份特权**：读者知道主角的真实身份，剧中人不知道
   - 例：哈利在动物园让玻璃消失，读者知道他不是普通小孩，德思礼一家不知道
2. **未来特权**：读者知道即将发生什么（或主角知道），其他人蒙在鼓里
   - 例：主角知道三天后会有兽潮，正在暗中准备
3. **能力特权**：读者看到主角获得了金手指，但剧中角色以为他还是废物
   - 例：药老出现，读者知道萧炎有了恢复的希望，家族不知道
4. **视角特权**：读者从上帝的叙述中获得了剧中角色不知道的背景信息
   - 例：读者看到反派在密谋陷害主角，但主角一无所知

### 案例拆解

**《哈利·波特与魔法石》第二章**
哈利在动物园让玻璃消失，把表哥关进蟒蛇笼。他自己不知道为什么，德思礼一家也不知道。但读者在这一刻知道了：哈利不是普通小孩。
德思礼一家始终把哈利当怪胎，读者从一开始就知道他们大错特错。

**《诡秘之主》第二章**
周明瑞附身于刚自杀的克莱恩，拥有对方记忆碎片，但周围的人没有一个发现换魂。
读者和主角共享这个秘密，接下来每一次社交互动都自带张力。

**《完美世界》第二章**
石昊被夺走至尊骨，读者看到这个秘密，但村里人不知道他曾经是天生至尊。
每次有人拿"没父母的野孩子"嘲笑他，读者都会想：等你们知道他曾经是什么人……

### 执行要点

- 特权信息必须在**一个具体事件**中展示（不是旁白介绍）
- 金手指展现方式：必须通过行动效果，而非属性面板
- 特权信息最好与第一章的落差直接关联
- 制造最少一层"观众知情、角色不知情"的结构

## 第三章：还小账，立新标

### 原理

很多作者写到第三章就开始铺世界观、开主线支线、拉势力关系网。结果读者弃了。

因为读者在前两章憋了一肚子情绪，等着看主角打回去、用金手指干点什么、验证自己的预判。如果第三章不满足这些情绪反而塞信息，读者会觉得被骗了。

第三章不能太贪心。别急着写"大的要来了"，先还一笔小账：一个小小的报复、一次小小的反击。让读者获得一次情绪释放，然后立刻划下一条新的期待线。

### 还小账的三种方式

1. **力量验证**：让主角用金手指完成一件小事（别人做不到的）
   - 例：萧炎吸收斗气恢复实力，虽然远不如从前但方向明确了
2. **预判兑现**：前面铺垫的冲突在第三章得到第一次回应
   - 例：被嘲笑的主角用事实证明自己在变强
3. **选择宣示**：主角主动做了一个决定，展现成长态度
   - 例：甄嬛决定"装病避宠"，不再被动等命运安排

### 立新标的三种方式

1. **时间标**：定下一个可预期的未来时刻
    - 例："三年之约"：云岚宗之战
2. **距离标**：明确近在咫尺的下一级目标
   - 例：先找到下一味药材、先突破第一层
3. **状态标**：锁定一个可量化的状态变更
   - 例：三个月内恢复三段斗之力

新目标必须是 3-10 章内可达成的具体目标。

### 案例拆解

**《斗破苍穹》第三章**
萧炎没有挑战退婚的纳兰嫣然。他接受药老训练，定下"三年之约"。
读者心里有了明确的坐标：云岚宗之战，纳兰嫣然会后悔的。
有方向的期待比一顿狂打更让人上头。

**《凡人修仙传》前三章**
韩立测试灵根，结果是资质最差的四灵根。他选择拜入七玄门，得到了一枚来历不明的神秘小瓶。
第一章展现落差（灵根太差修仙无望），第二章给出特权信息（小瓶能催熟植物），第三章验证功能（发现小瓶的秘密）+钉下目标（靠小瓶稳步提升）。

## 三章递进情绪曲线

```
第1章 ──→ 第2章 ──→ 第3章
同情    焦虑    满足+期待
 ↓        ↓        ↓
落差被看见  特权被握紧  小账被收回
                 新目标被放下
```

- 第一章结束：让读者同情主角，想看他翻身
- 第二章结束：让读者焦虑，迫切想知道下一步
- 第三章结束：让读者满足（小账还了）+ 期待（新目标立下了）

## 高潮密度

- 小高潮：每 2-3 章一个。
- 中高潮：每 8-10 章一个。
- 大高潮：每卷一个，前 3-5 章必须铺线索。
- 高潮后 1-2 章必须写出后效：主线推进、关系变化、权力格局改变、角色状态变化。

高潮结构建议：

1. 铺垫蓄力：矛盾积累，压力递增。
2. 爆发点：冲突达到顶点。
3. 正面对抗：选择、行动、代价同时落地。
4. 余波收束：结果影响到下一段剧情。


# 章节密度与节奏规则

网文章节的字数、密度、段落和断章规则。

## 字数与爽点密度

- 每300字至少1个爽点/看点
- 每500字至少1个钩子
- 每1000-1500字至少1个完整悬念
- 目标字数允许区间为目标的±10%

## 叙事段长度

- 叙事段40-120字（3-5行手机屏）
- 对话段落天然短，不需并段
- 连续3个及以上短段（<40字）并列连排属于违规
- 短段仅在以下场景允许：(1)开场前300字反转金句 (2)章末钩子最后一句 (3)单章≤3个爆点短段
- 三个场景合计一章最多5个短段，超过即"堆砌电报体"
- 审核硬阈值：60%以上叙事段<40字 → 段落过碎，触发返工

## 80/20 断章硬尺

永远不要在一章里把本章故事讲完：写到80%，剩下20%留给下一章。

章末必须断在 action-climax 的那一刻：主角刚放大招尚未见效 / 刚拔刀尚未落下。

## 断章钩子轮换

每章结尾至少留下一个缺口。钩子必须轮换，不能每章都靠同一种悬念。

- 悬念类：关键信息即将揭露、秘密即将暴露、真相刚露一角。
- 危机类：强敌降临、陷阱触发、计划失败、背叛发生。
- 反转类：身份即将揭露、敌友转换、局势逆转、意外变故。
- 期待类：即将突破、宝物将到手、比赛结果、考核成绩。
- 情感类：误会将解、重逢/离别、告白回应、关系破裂。
- 信息类：重大消息、阴谋揭露、世界观重大信息、系统提示。

钩子必须在下一章前 1/3 处给反馈。可以不完全回收，但要让读者感觉上一章的问题被正面处理了。

## 节奏变化

```
紧张 → 缓解 → 新紧张 → 更紧张
```

- 紧张场景用短句加速（连续短句排比）
- 抒情或思考段落适当放慢（长句+感官细节）
- 避免单调的句子开头：不要连续以"他/她"开头
- 句式长短错落：长句用于环境/心理，短句用于动作/冲突

## 场景规范

- 新场景前100字让读者知道谁在场、在哪儿、发生什么
- 场景转换必须有过渡，禁止前一刻在A地、下一刻毫无过渡出现在B地
- 场景切换需通过感官细节建立新空间感

## 高潮前后规则

- **高潮前**：大高潮前3-5章必须有线索埋设
- **高潮后**：爆发后1-2章必须写出改变（主线推进、人设成长、关系变化），不能直接跳到下一个蓄压

## 类型变体指南

### 玄幻/仙侠（起点主流）
- **第一章锚点**：展现天赋/地位/血脉的最高点
- **金手指形态**：老爷爷、系统、特殊体质、神器转世
- **第三章目标**：恢复实力到某个可见刻度
- **核心情绪**：憋屈 → 希望 → 逆袭预感

### 都市/现实
- **第一章锚点**：职场地位/家庭关系/金钱权力
- **金手指形态**：重生记忆、特殊技能、隐藏身份
- **第三章目标**：在某个可证实的方面证明自己
- **核心情绪**：不甘 → 谋划 → 第一次出手成功

### 悬疑/诡异
- **第一章锚点**：正常生活 → 卷入异常事件
- **金手指形态**：特殊视角、隐藏信息、预知能力
- **第三章目标**：活过第一轮危机 / 找到第一个线索
- **核心情绪**：困惑 → 恐惧 → 掌控第一条线索后的镇定

### 系统流
- **第一章锚点**：废材/普通人的生活
- **金手指形态**：系统面板在第一章末尾或第二章激活
- **第三章目标**：完成第一个系统任务
- **核心情绪**：茫然 → 发现系统 → 新手任务

### 无限流
- **第一章锚点**：被拉入主神空间
- **金手指形态**：特殊天赋技能
- **第三章目标**：第一个副本中完成第一次生存
- **核心情绪**：慌乱 → 规则学习 → 初步站稳脚跟

## 五条红线（绝对禁止）

1. **300字内无主角**：第一章前200字必须出现主角，300字内让他做第一个行动
2. **第一章超过2个场景**：读者没耐心跟着换场景，越少越好
3. **金手指靠旁白介绍**："他有XX系统"不如"他在XX场景里无意中用出了XX能力"
4. **第三章开新地图推世界观**：先把前两章的账还了再谈世界
5. **章末没有钩子**：每章最后一句话必须制造"想知道后来怎么了"的冲动

## 反模式诊断

| 症状 | 诊断 | 方案 |
|------|------|------|
| 读者反馈"看了三章不知道主角什么样" | 第一章没有锚点 | 第一章前500字加一个"主角曾经高光"的具体场景 |
| 读者反馈"金手指出现太突兀" | 第二章没有事件铺垫 | 金手指必须通过一次具体事件展现，不是系统弹出 |
| 读者反馈"看了三章不知道要干嘛" | 第三章没有钉目标 | 加一个可量化的短期承诺（时间/距离/状态） |
| 追读率低但收藏还行 | 三章情绪曲线太平 | 检查落差幅度/特权信息类型/小账回收力度 |
| 跳订率高 | 第三章开了不该开的新线 | 把第三章新信息推迟到第四章 |

## 自检清单

输出前三章后逐条核对：

### 第一章
- [ ] 前200字主角出现
- [ ] 前300字最后一句是戏剧性反转
- [ ] 800字内触发核心冲突
- [ ] 场景 ≤ 2 个，互动人物 ≤ 3 个
- [ ] 落差三要素齐全：锚点、现状、对比触发器
- [ ] 结尾有钩子（悬念/疑问/未完成的冲突）

### 第二章
- [ ] 有一项明确的特权信息交给读者
- [ ] 特权信息在具体事件中展示，非旁白
- [ ] 金手指已通过行动效果展现
- [ ] 特权信息与第一章落差有关联
- [ ] 结尾让读者焦虑"接下来会怎样"

### 第三章
- [ ] 前两章积累的情绪得到了一次释放
- [ ] 已通过一个具体事件验证了主角的某种进步
- [ ] 钉下了3-10章内可达成的具体短期目标
- [ ] 没有开多余的新线路/新势力/新世界观
- [ ] 结尾制造了新期待（非重复旧情绪）
