# 剧本改编

改编要保住作者想让观众经历的选择、代价与情感回报。原著章节与剧集不必一一对应；改编方案也不等于缩短后的剧情摘要。

## 先确定本次改什么

- 读取用户指定的材料、已接受的取舍和目标形态。只有书名时不能凭记忆宣称完成原著分析；缺全文时说明实际读到的范围。
- 区分不能改的核心事实、可探索部分和已授权的改编幅度。集数、时长和制作方式已给出就直接使用；只做价值快评时不必先问齐制作参数。
- 用户已经确认方案时，沿用方案进入指定任务，不再重做选型。若要改变主角、结局、核心关系或忠实程度，先说明具体差异与影响。

## 工作方式

1. **找戏剧功能**：识别谁追求什么、遭到什么阻力、作出什么选择、付出什么代价，以及观众何时知道关键事实。长材料的覆盖与提取方法见 [原文分析](source-analysis.md)。
2. **做取舍**：给出保留、删减、合并、重排与新增连接的方案，每项重大取舍都能指回原文位置，并说明失去的功能由谁承担。人物和场所归并、心理描写外化见 [改编决策](adaptation-decisions.md)。
3. **检验新因果**：被挪到前面的揭示是否提前泄密？合并后的角色能否同时拥有这些经历和信息？删掉的场景是否带走了后续行为的原因？
4. **交付本次范围**：价值评估给出建议、依据和材料缺口；改编方案给出故事核心、主要取舍、人物与事件对应关系、建议结构及制作难点。用户要改编正文时，在方案已明确的范围内读取 [场次写作](scene-writing.md) 完成正文。

## 交接与边界

- 输出中分清原文事实、推断和改编新增。未获采用的候选不写成既定故事事实。
- 需要保存到剧本工作区时，先加载「剧本工具使用规范」，按现有资源契约写入；分析源小说与写入目标剧本要分别定位，不覆盖原作。
- 不强制砍掉固定数量的角色、把所有题材改成爽剧，或用宣传性的商业判断代替材料分析。
- 不启动出图、配音或视频生成；制作难点作为取舍依据交给作者。
