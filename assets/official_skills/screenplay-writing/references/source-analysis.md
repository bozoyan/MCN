# 从原文找到可改编的戏

## 按材料规模读取

短篇或用户点名的章节直接精读。长篇先看目录、简介及已有摘要以确定结构，再读取关键选择、关系转折和结局所在原文。摘要用于导航，不能充当逐句改写的来源。

抽样分析只给抽样结论。列出已读范围与未覆盖部分，不把“前几章有潜力”写成“全书改编结构已验证”。批量处理时保留最小交接：已读位置、重要事实、未解决问题和下一批起点；不为短任务建立整套文件流水线。

## 记录事件的作用

对会影响取舍的片段，记录：

| 项目 | 要回答的问题 |
|---|---|
| 来源 | 哪一章、哪场、哪段能找到它？必要时引用最短辨识片段 |
| 行动 | 谁为了什么做了什么？ |
| 反制 | 什么人、制度或条件让原计划失效？ |
| 结果 | 哪个信息、关系、资源或行动机会发生变化？ |
| 依赖 | 它需要哪项前置事实，又支撑哪个后续事件？ |
| 观看体验 | 观众在此处理解、期待、担忧或重新判断什么？ |

不需要给每段文字套表。优先记录一旦删改就会影响主线、人物选择或信息释放的片段。

## 先按因果聚合，再讨论分集

小说可能分三章写一次谈判，也可能在一章里跨过数月。按一个目标的展开与结果聚合事件，找出自然的局部结果和下一步压力；之后才按目标集长调整。

角色归并先查别名、关系与实际功能。同名不必然是同一人；缺乏证据时保留待核对，不靠名字相似自动合并。特别注意某个角色是否同时承担目击、误导和揭示功能，这些功能可能要求不同的知情范围。

## 快评应当能被反驳

以材料中的具体选择、关系和场面说明改编潜力，也指出障碍：关键变化只存在于内心、长线回报依赖大量铺垫、人物过多但各有必要功能、核心戏难以在目标时长内成立。

“适合改编”的结论至少说清打算保留什么、压缩什么、哪个缺口仍要补读。不要使用未经验证的播放量、付费转化率或市场保证。
