# 剧本审查

评价当前稿件是否实现作者的目标。先验证能指认的事实，再判断戏剧效果；不用模板符合度或无依据分数代替阅读。

## 确定范围

读取用户要求审查的实际稿件及必要前后文、原著或设定。用户只要求看一场就围绕该场；缺失上下文只限制依赖它的结论，不阻止其他问题的检查。

在剧本工作区读取正文前加载「剧本工具使用规范」。只有大纲时审查结构，不能声称对白、表演节奏或正文已通过。

## 执行审查

1. 核对原意与范围：有没有擅改已确认的关系、结局、题材或时间要求？改编新增是否被误称为原著事实？
2. 核对引用与连续性：人物、地点、场次和物件是否真实存在，变化有没有前因，角色是否只知道其能接触到的信息？
3. 判断场景作用、选择与结果、对白回应、必要信息的可见性。按实际交付物使用 [审查尺度](review-rubric.md)，不要求所有场景同一种结构。
4. 涉及目标时长、视频描述或证据强弱时读取 [证据与时长](evidence-and-timing.md)。没有音视频时不推断实际表演、运镜、口型或成片质量。

## 输出可执行的问题

每项包含：具体位置、最小必要证据、对理解或交付的影响、建议达到的修订结果。优先列出会破坏剧情理解、作者约定或制作交接的问题，再给少量风格建议。

- **明确问题**：已有材料足以证明的冲突、遗漏或不成立的因果。
- **待核对**：缺少关键输入，说明缺什么及它影响哪项判断。
- **可选建议**：另一种创作选择，说明收益与代价，不伪装成错误。

若未发现明确问题，说明已审范围和验证限制。自检就标明自检，不声称独立复审或脚本验证。用户只要求审查时不直接改正文；要求审改时在授权范围内修订，并核对受影响的上下文。
