# 剧本对白

先判断角色希望这句话让对方做什么，再判断它是否好听。台词的效果来自目标、信息差和关系风险，不能只靠口头禅区分人物。

## 阅读与诊断

读取待改对白、前后动作、说话者及其知情范围。用户只给一段时按这段处理，缺失背景会影响结论的地方标明，不编造完整前史。

找出主要问题：重复解释、听者没有回应、所有人共享同一种判断方式、意图全部直说、故作含糊，或表演提示挤占实际行动。人物有意直白、啰嗦、笨拙或使用方言时，先理解其作用。

## 修改

1. 明确每个人当前想得到什么、有什么筹码、什么不能说。缺少这层动机时，先修场景逻辑，单换措辞解决不了。
2. 让下一句话回应上一句或刚发生的动作：接受、反驳、回避、试探、转移或反过来设条件。答非所问也应有目的。
3. 必要背景通过争议、责任、证据或关系变化进入。双方早已知道的信息，不为观众再完整复述一遍。
4. 用角色在意什么、相信何种证据、如何维护关系区分声音，再调整词汇和节奏。保留作者既定语体。
5. 改后连读完整对话及前后动作，确认没有改变既定剧情事实和知情时机。

具体诊断与修订方法见 [对白手艺](dialogue-craft.md)；需要示范怎样在不改事实的情况下重写时，读取 [局部修订示例](revision-example.md)。

## 交付边界

用户要改稿就交付修改后的目标范围，只有说明取舍有帮助时附简短说明。不要附逐句动机分析充当对白。涉及剧本工作区写入时加载「剧本工具使用规范」，使用实际人物和正文元素；小说对话则保留原有叙述格式。

只改台词不意味着可以随意增加关键道具、秘密或关系。若好的改法依赖这些变化，提出建议并说明依赖，不偷偷写成既成事实。
