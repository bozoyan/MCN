## 三、踩过的环境坑与修复(重要,复发时对照)

1. **`storage.googleapis.com` / `static.rust-lang.org` 连不上**
   现象:fvm install / rustup 下载失败、SSL_ERROR_SYSCALL。
   修复:全量走国内镜像(见第二节的 `PUB_HOSTED_URL` / `FLUTTER_STORAGE_BASE_URL` / `RUSTUP_DIST_SERVER`)。

2. **clang 报 `conflicting deployment targets, both '27.2' and '27.2'`**
   根因:`~/.zshrc` 里 `export CC/CXX=/opt/homebrew/opt/llvm/bin/clang++` 把 Homebrew LLVM 顶到了 Xcode 工具链前面(同 flutter/flutter#178195 的环境问题)。
   修复:构建前 `unset CC CXX CPATH`,不要改 .zshrc(用户的 LLVM 可能别处要用)。

3. **rustup 官方 shell 安装脚本失败(`xattr: invalid option -- y`)**
   macOS 27 的 `xattr` 移除了 `-y` 选项。修复:用 `brew install rustup`。

4. **`dlopen ... mis-aligned LINKEDIT string pool` / `FRB content hash does not match`**
   根因:rust-lang/rust#157750——rustc 内部 strip 在 macOS 26+ 新 dyld 下产出未对齐 LINKEDIT。`ld_classic`、`-Wl,-no_fixup_chains`、外部 `strip -x` 全都修不了。
   修复:`third/fjs/libfjs/Cargo.toml` 的 `[profile.release]` 改 `strip = false`,已记录到 `third/fjs/REVERIC_PATCH.md`。副作用:产物不 strip、体积变大,可接受。
   另:失败重试前先 `rm -rf third/fjs/build`(脏缓存会持续报 hash 不匹配)。

5. **`git ls-files ... returned non-zero exit status 128`**
   根因:`third/fjs/tool/artifact.py` 用 git 计算构建 key,项目 `.git` 被移除后无法构建。
   修复:`git init` + `git add -A`(新仓库,master 分支,无历史)。本项目将作为新的独立项目分支以后建到别的仓库。

## 四、魔搭 ModelScope 与 MOSS 双供应商(本次功能改动)

### 4.1 API 实测格式(均已通过)

- 魔搭(异步任务):`POST https://api-inference.modelscope.cn/v1/images/generations`,头 `Authorization: Bearer <MODELSCOPE_API_KEY>` + `X-ModelScope-Async-Mode: true`,返回 `task_id`;轮询 `GET /v1/tasks/{id}` + 头 `X-ModelScope-Task-Type: image_generation`,`RUNNING → SUCCEED/FAILED`,成功取 `output_images[0]`。
  参数:`model`(repo-id)、`loras`(单条字符串 / 多条 `{id: weight}`,≤6 个、权重和=1.0)、`size`(512x512-2048x2048)、`seed`(-1 随机)、`guidance`、`steps`(Turbo=8)、`image_url[]`。
- MOSS(同步):`POST https://api.mosi.cn/v1/images/generations`,Bearer 认证,直接返回 OpenAI 格式 `data[0].url`(仅 url、仅 1 张)。
  参数:`model`、`prompt_enhance`、`negative_prompt`、`size`(16 倍数)、`output_watermark: {enabled}`。

## 五、四个出图入口

1. **画布(image_composer)**:工具栏「调节」按钮 → 尺寸 + LoRA/参数 → 随任务冻结落库。
2. **封面工作台(designer)**:比例下方「高级参数」区块,提交透传 extras。
3. **聊天窗口(composer)**:发送键左侧 ✨ 按钮 → 出图对话框(`lib/desktop/widgets/ai/chat/image_dialog.dart`):默认底座 `Qwen/Qwen-Image-2.1-Turbo`(可切任意已配置模型)、尺寸、LoRA/参数、提示词;生成结果以图片卡片插入聊天流并入库图库。
4. **人物拍照/头像弹窗(character_profile_editor)**:「额外要求」上方新增尺寸 + LoRA/参数;确认后**直接调用生图服务**(不经 Agent handoff,参数原样下发),结果自动入库:头像 → `updateCharacterAvatarAndPhotos` 直接应用;照片 → `addCharacterPhotos` 进照片集。
