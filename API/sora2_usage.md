# Sora2 视频生成功能使用说明

## 版本信息
- **版本**: 1.1.0
- **创建日期**: 2025-01-10
- **更新日期**: 2025-01-10
- **适用程序**: storyboard_generator.py

## 功能概述

Sora2 视频生成是基于 BizyAir API 的 AI 视频生成功能，支持两种模式：

1. **文生视频 (Text-to-Video)**: 通过文本描述生成视频
2. **图生视频 (Image-to-Video)**: 通过图片和文本描述生成视频

## 功能位置

打开 `storyboard_generator.py` 后，在左侧导航栏中可以看到：
- 🏠 首页
- 🎬 分镜生成
- 📹 视频生成
- 🤖 **Sora2生成** ← 新功能在这里
- ⚙️ 设置

## API 配置

### 1. 点击 "API Settings" 按钮

### 2. 选择 API 密钥来源

#### 选项1: 文件密钥 (推荐)
- 创建一个文本文件（如 `api_keys.txt`）
- 每行输入一个 API 密钥
- `#` 开头的行会被忽略（可用于添加注释）

示例文件内容：
```
# BizyAir API 密钥列表
sk-xxxxxxxxxxxxxxxxxxxxxxxxx
sk-yyyyyyyyyyyyyyyyyyyyyyyyy
sk-zzzzzzzzzzzzzzzzzzzzzzzz
```

#### 选项2: 系统变量
使用环境变量 `SiliconCloud_API_KEY`

#### 选项3: 密钥文本
直接在对话框中输入 API 密钥，每行一个

### 3. 配置 API 参数

- **文生视频 Web App ID**: 默认 `42921`
- **图生视频 Web App ID**: 默认 `42936`
- **API URL**: 默认 `https://api.bizyair.cn/w/v1/webapp/task/openapi/create`

### 4. 点击 "保存设置"

## 使用方法

### 单个视频生成

#### 文生视频模式

1. 在 "生成模式" 下拉框选择 **"文生视频"**
2. 在 "视频提示词" 输入框输入描述文字，例如：
   ```
   一个美丽的日落场景，海浪轻轻拍打着沙滩，天空呈现出橙红色的渐变
   ```
3. 在 "视频参数" 中选择宽高比（如 `9:16`, `16:9`, `1:1` 等）
4. 点击 **"单个生成"** 按钮
5. 等待视频生成完成（通常需要 5-10 分钟）

#### 图生视频模式

1. 在 "生成模式" 下拉框选择 **"图生视频"**
2. 在 "上传图片" 区域：
   - 拖拽图片到虚线框内，或
   - 点击 "选择图片文件" 按钮
3. 在 "视频提示词" 输入框输入描述文字，例如：
   ```
   图片中的女子正在微笑，背景有柔和的光线，整体氛围温馨浪漫
   ```
4. 在 "视频参数" 中选择宽高比
5. 点击 **"单个生成"** 按钮
6. 等待视频生成完成

### 批量视频生成

#### 文生视频批量生成

1. 在 "批量任务列表" 输入框中，每行输入一个提示词：
   ```
   提示词1
   提示词2
   提示词3
   ```
2. 或点击 "从文件加载" 按钮导入文本文件
3. 选择视频模式和参数
4. 点击 **"批量生成"** 按钮
5. 系统会自动按顺序生成所有视频（每个任务间隔 30 秒）

#### 图生视频批量生成

1. 准备好多个图片文件
2. 在 "批量任务列表" 中按以下格式输入：
   ```
   图片路径1|提示词1
   图片路径2|提示词2
   图片路径3|提示词3
   ```
   示例：
   ```
   /path/to/image1.png|描述图片1的内容
   /path/to/image2.jpg|描述图片2的内容
   /path/to/image3.jpeg|描述图片3的内容
   ```
3. 点击 **"批量生成"** 按钮

## 功能特性

### 1. 实时进度显示
- 任务状态卡片显示每个视频的生成进度
- 显示已用时间和当前状态
- 批量进度条显示整体完成情况

### 2. 多密钥轮询
- 支持配置多个 API 密钥
- 自动轮询使用，提高并发能力
- 在密钥状态标签显示可用密钥数量

### 3. 视频结果管理
- 生成完成后显示视频 URL
- 支持一键复制 URL
- 支持在浏览器中打开视频
- 自动下载到 `output` 文件夹

### 4. 任务管理
- 支持查看所有任务的执行状态
- 实时日志输出
- 失败任务显示错误信息

## 视频参数说明

### 宽高比 (Aspect Ratio)
- **9:16**: 竖屏视频（适合 TikTok、Reels、Shorts）
- **16:9**: 横屏视频（适合 YouTube、电视）
- **1:1**: 方形视频（适合 Instagram）
- **4:3**: 传统比例
- **3:4**: 竖屏方形
- **21:9**: 超宽屏

### 提示词编写建议

1. **详细描述场景**: 包含主体、环境、动作、氛围
2. **使用英文**: API 对英文提示词支持更好
3. **控制视频长度**: Sora2 默认生成约 5 秒视频
4. **指定风格**: 可以添加 "电影感"、"动画风格" 等描述

示例提示词：
```
A cinematic shot of a futuristic city at night, neon lights reflecting on wet streets,
flying cars passing by, cyberpunk style, high quality, detailed
```

## 常见问题

### Q1: 视频生成失败怎么办？
A: 检查以下几点：
- API 密钥是否配置正确
- 网络连接是否正常
- 提示词是否过长（建议不超过 200 字）
- 查看日志输出了解具体错误信息

### Q2: 生成时间太长？
A: Sora2 视频生成通常需要 5-10 分钟，这是正常现象。如果超过 20 分钟仍未完成，可能是：
- API 服务器负载过高
- 任务队列中等待处理
- 网络延迟

### Q3: 如何提高生成速度？
A:
- 配置多个 API 密钥进行轮询
- 使用更简洁的提示词
- 避免在网络高峰期使用

### Q4: 生成的视频质量如何？
A: Sora2 是 OpenAI 的最新视频生成模型，质量较高，但仍需：
- 使用详细准确的提示词
- 选择合适的宽高比
- 多次尝试不同提示词

## 文件输出

### 输出位置
- 默认输出目录: `output/`
- 文件命名格式: `sora2_{模式}_{时间戳}.mp4`
  - 文生视频: `sora2_t2v_143022.mp4`
  - 图生视频: `sora2_i2v_143022.mp4`

### 日志文件
- 日志位置: `logs/sora2_generation.log`
- 包含所有任务的详细执行记录
- 可用于问题排查
