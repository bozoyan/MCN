# v0.5.5 全屏预览修复、弹窗选中态与生成计时

更新日期:2026-11-01
涉及文件:`lib/shared/components/reveric_image_preview.dart`(路径解析兜底、SVG 关闭按钮)、`lib/desktop/widgets/ai/chat/image_dialog.dart`(模型选中态修复)、`lib/shared/widgets/ai/tools/character_image_tool_card.dart`(生成计时)、`lib/desktop/features/production/support.dart`、`pubspec.yaml`(0.5.4 → 0.5.5)

---

## 一、问题与根因

1. **画布「查看」/双击全屏显示「无法预览此文件」但卡片能显示图**:画布媒体读取(`ProductionMediaFile.read`)返回的是 `file_workspaces/...` **存储相对路径**,卡片缩略组件内部自行解析所以正常;全屏组件直接 `Image.file(相对路径)` 找不到文件。
2. **出图弹窗输入描述后模型下拉消失、无法再选**:`availableModelOptionsForKind` 每次 build 生成新列表,而 `AiModelOption` 未重写 `==`,下拉按实例比较选中态——输入文字触发重建后,已选模型与列表失配,选中态消失、尺寸/参数区随之隐藏。
3. **对话出图「执行中…」无时长感知**:生成中徽章没有计时。
4. **全屏预览右上角关闭按钮显示异常**:共享组件误用 Material 字体图标(`Icons.close`),与项目 SVG 图标体系不一致导致渲染问题。

## 二、修复内容

### 2.1 全屏预览路径解析兜底(`reveric_image_preview.dart`)

组件内部对 `imagePath` 统一做 `RevericPaths.resolveStored`(相对路径解析为绝对、绝对原样),画布相对路径与对话绝对路径两种来源都稳定打开;关闭按钮改用项目 SVG 图标 `RevericIcons.close`(黑底圆片样式),与全项目图标体系一致。

### 2.2 出图弹窗选中态修复(`image_dialog.dart`)

`options` 列表用 `useMemoized` 缓存(settings 不变时列表实例稳定);当前默认模型改按 id 在缓存列表内归一化,保证所有可能的选中对象来自同一列表实例——输入描述、切换尺寸等任何重建都不再丢失选中态。

### 2.3 对话出图生成计时(`character_image_tool_card.dart`)

图片卡「执行中…」徽章缀滚动秒数(如「执行中… · 12s」),进入成功/失败终态即停表;组件 dispose 时清理计时器。
