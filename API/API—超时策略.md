  1. 统一超时策略

  - ✅ 所有模式统一使用 5分钟短超时
  - ✅ 所有请求都通过 request_id 进行异步查询，避免长时间占用连接

  2. Sora2 模式查询策略（文生视频 / 图生视频）

  - ⏱️ 最长等待: 60分钟
  - 📊 前5分钟: 每 60秒 查询一次（低频）
  - 📊 5分钟后: 每 20秒 查询一次（高频）
  - 🎉 优化效果: API 调用次数从 ~390次 减少到 ~240次，减少 38.5%

  3. 其他模式查询策略（单图片 / 首尾帧 / 视频换人物）

  - ⏱️ 最长等待: 30分钟
  - 📊 前3分钟: 每 30秒 查询一次（低频）
  - 📊 3分钟后: 每 10秒 查询一次（高频）
  - 📊 优化效果: 前3分钟减少了 66% 的无效高频调用

  4. 批次任务间隔

  - ✅ 设置为 60秒（1分钟） 间隔
  - ✅ 避免同时发起大量请求导致 API 限流
