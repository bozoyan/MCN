## 更新内容

### 1. 宽高比选择方式优化

#### 变更前
- 使用下拉菜单 (ComboBox) 选择宽高比
- 包含 6 个选项：9:16, 16:9, 1:1, 4:3, 3:4, 21:9

#### 变更后
- 使用单选按钮组 (QRadioButton) 选择宽高比
- 仅保留 2 个常用选项：
  - **9:16 (竖屏)** - 适合 TikTok、Reels、Shorts
  - **16:9 (横屏)** - 适合 YouTube、电视

### 2. 实现细节

#### 2.1 UI 组件变更
```python
# 旧代码 (ComboBox)
self.aspect_ratio_combo = ComboBox()
self.aspect_ratio_combo.addItems(["9:16", "16:9", "1:1", "4:3", "3:4", "21:9"])

# 新代码 (QRadioButton)
self.aspect_ratio_9_16 = QRadioButton("9:16 (竖屏)")
self.aspect_ratio_9_16.setChecked(True)
self.aspect_ratio_16_9 = QRadioButton("16:9 (横屏)")
```

#### 2.2 样式设置
- 白色文字 (#ffffff)
- 字体大小 13px
- 水平间距 20px
- 添加弹性空间 (addStretch) 保持布局美观

#### 2.3 方法更新
- `set_aspect_ratio(ratio)` - 设置选中的宽高比
- `get_aspect_ratio()` - 获取当前选中的宽高比值

### 3. 用户体验提升

#### 3.1 简化选择
- 从 6 个选项减少到 2 个最常用选项
- 避免用户在选择时犹豫
- 提高操作效率

#### 3.2 直观显示
- 单选按钮自带圆形选择指示器
- 选项含义更清晰（竖屏/横屏）
- 符合常见视频平台标准

#### 3.3 保持兼容性
- 配置文件格式不变
- API 接口不变
- 历史设置自动迁移

### 4. 技术实现

#### 4.1 导入更新
```python
from PyQt5.QtWidgets import (..., QRadioButton, ...)
```

#### 4.2 默认值
- 默认选择：9:16 (竖屏)
- 配置文件默认值：aspect_ratio: "9:16"

#### 4.3 数据流
1. 用户点击单选按钮
2. `get_aspect_ratio()` 读取选中状态
3. 传递给视频生成线程
4. API 请求使用该参数

### 5. 代码质量

#### 5.1 代码简化
- 移除不必要的选项处理逻辑
- 减少界面复杂度
- 提高可维护性

#### 5.2 样式一致性
- 符合深色主题设计
- 与其他 UI 组件风格统一
- 保持良好的可读性

## 用户指南

### 使用方法
1. **选择宽高比**：点击"9:16 (竖屏)"或"16:9 (横屏)"单选按钮
2. **生成视频**：按正常流程生成视频
3. **自动保存**：选择会自动保存到配置文件

### 选择建议
- **竖屏视频 (9:16)**：
  - 抖音、快手等短视频平台
  - Instagram Reels
  - YouTube Shorts

- **横屏视频 (16:9)**：
  - YouTube 正常视频
  - Bilibili 视频
  - 电视、电脑播放
