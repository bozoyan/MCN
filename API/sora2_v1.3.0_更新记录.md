## 更新内容

### 1. 图片上传组件优化

#### 问题分析
原设计存在以下问题：
- 图片预览区域和选择按钮分离，造成视觉混乱
- "请拖拽图片到这里"文字和"选择图片文件"按钮功能重叠
- 边框设计不够美观，缺乏层次感
- 用户体验不够直观

#### 解决方案
重新设计了 `Sora2ImageDropWidget` 组件，采用统一的容器设计：

### 2. 新设计特性

#### 2.1 统一容器布局
```python
# 创建一个容器来整合拖拽区域和按钮
container = QFrame()
container.setFixedSize(280, 200)
container.setStyleSheet("""
    QFrame {
        border: 2px dashed #606060;
        border-radius: 10px;
        background-color: #252525;
    }
    QFrame:hover {
        border: 2px dashed #4a90e2;
        background-color: #2a2a3a;
    }
""")
```

**特点**：
- 虚线边框（#606060），悬停时变为蓝色（#4a90e2）
- 圆角设计（10px）
- 深色背景（#252525）
- 悬停时背景变亮（#2a2a3a）

#### 2.2 图片预览区域
```python
self.image_label = QLabel()
self.image_label.setFixedSize(260, 140)
```

**特点**：
- 深色背景（#1e1e1e）与外层容器形成层次

- 默认提示文字：📁\n\n拖拽图片到这里\n或点击下方按钮选择

### 4. 视觉对比

#### 优化前
```
┌─────────────────────────────┐
│  [虚线边框 - 独立的图片区域]  │
│  "请拖拽图片到这里"           │
└─────────────────────────────┘
         ↓
    [选择图片文件] 按钮
```
**问题**：两个独立元素，视觉不统一，功能重叠

#### 优化后
```
┌─────────────────────────────┐
│  [统一的虚线边框容器]         │
│  ┌─────────────────────┐   │
│  │  📁                 │   │
│  │  拖拽图片到这里      │   │
│  │  或点击下方按钮选择  │   │
│  └─────────────────────┘   │
│  [ 📷 选择图片 ]            │
└─────────────────────────────┘
```
**优点**：
- 统一容器，视觉协调
- 层次分明（外层边框 → 内层预览区）
- 文字提示更清晰
- 悬停效果引导用户操作

### 5. 技术实现细节

#### 5.1 尺寸设计
- 容器：280 x 200px
- 预览区：260 x 140px
- 按钮：高度 32px，宽度自适应
- 内边距：10px
- 间距：10px

#### 5.2 颜色方案
| 元素 | 普通状态 | 悬停状态 | 按下状态 |
|------|----------|----------|----------|
| 容器边框 | #606060 | #4a90e2 | - |
| 容器背景 | #252525 | #2a2a3a | - |
| 预览区背景 | #1e1e1e | - | - |
| 按钮背景 | #3a3a3a | #4a4a4a | #2a2a2a |
| 按钮边框 | #505050 | #606060 | - |

#### 5.3 圆角设计
- 外层容器：10px（较大圆角，柔和）
- 内层预览区：6px（较小圆角，精致）
- 按钮：6px（统一风格）
