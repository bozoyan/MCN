# v1.0.1 聊天出图修复与参数记忆

更新日期:2026-10-31
涉及文件:`lib/desktop/widgets/ai/chat/image_dialog.dart`(生成按钮条件、尺寸回显、参数记忆读写)、`lib/shared/models/image/chat_image_memory.dart`(新增)、`test/shared/models/image/chat_image_memory_test.dart`(新增)

---

## 一、问题与根因

用户实测(系统 macOS 27.2,聊天窗口下方 ✨ 出图入口):

1. **输入画面描述后「生成」按钮变灰,无法出图**。根因:`image_dialog.dart` 中生成按钮的 `onPressed` 三元条件写反了——「模型未选 / 提示词为空 / 生成中」成立时按钮反而可点(但 `generate()` 内部守卫早退,点击无效果);三项全部正常时 `onPressed` 为 `null`,按钮呈禁用灰色。即任何状态下都无法真正生成。
2. **图片尺寸选择后不回显**。根因:`_ChatImageSizeSelector` 的下拉 `value` 硬编码为 `options.first`,选中新尺寸后控件仍显示「默认」档,观感为「无法自定义选择尺寸」。
3. **出图参数不记忆**:模型、尺寸、LoRA/采样参数每次打开弹窗都回到初始值。

对照入口:头像/拍照弹窗(`character_profile_editor.dart`)因尺寸下拉正确用 `firstWhere` 回显、按钮条件正确,故表现正常;两处差异即为本次修复依据。

## 二、修复与新增内容

### 2.1 生成按钮条件修复(`image_dialog.dart`)

按钮可用条件改为正向判断:`模型已选 && 提示词非空 && 非生成中` 时 `onPressed` 指向 `generate()`,否则 `null` 置灰。与 `generate()` 内部守卫语义一致,消除「可点但无效 / 正常却置灰」的双重矛盾。

### 2.2 尺寸下拉回显修复(`image_dialog.dart`)

`_ChatImageSizeSelector` 新增 `selectedSize` 入参,`value` 改用 `options.firstWhere((option) => option.$1 == selectedSize, orElse: () => options.first)`,选中尺寸即时回显;尺寸不在当前渠道支持列表时回落显示「默认」。

### 2.3 出图参数记忆(新增 `chat_image_memory.dart`)

- 新模型 `ChatImageMemoryData`(`lib/shared/models/image/chat_image_memory.dart`):字段 `modelOptionId`(格式 `providerId::model`)、`size`、`extras`(复用 `ImageRequestExtras` 的 JSON 往返);存于 `app_settings` 单 key `chat_image_memory`,遵循 KV 表领域边界集中编解码约定(`.agents/rules/json.md`)。
- **恢复**:打开弹窗前经 `appSettingsDao.get` 读取;模型按记忆 id 匹配,失效时回落默认底座 Qwen/Qwen-Image-2.1-Turbo → 当前默认 → 第一个;尺寸经 `ProductionImageCapabilities` 校验仍被支持才恢复,否则回落默认档;extras 原样恢复。
- **保存**:点击生成时(`Navigator.pop` 前)写回本次使用的模型/尺寸/参数;空 extras 归一为 null 不落库;写入失败仅记 `[DB]` 日志,不阻断生成(error-handling 规则:DB 写入 try-catch + 日志)。
- 读写直接走 DAO,不进 `AppSettings` 全局状态,避免弹窗参数变更触发全局设置重建(参照 remote_bridge 持久化模式)。

### 2.4 构建环境恢复

`.git` 缺失导致 `third/fjs/tool/artifact.py` 构建失败(exit 128,即 v1.0.0 文档三-5 同款问题),已按文档方案执行 `git init` + `git add -A`(5757 个文件入暂存,无提交)。

## 四、遗留与说明

- 聊天里由 AI 主动发起的拍照(generate-avatar/generate-photo 工具通路)仍用硬编码尺寸,未扩 size/extras 白名单,沿 v1.0.0 遗留项。
- 参数记忆为全局单份:换模型时尺寸仍会重置(不同渠道尺寸表不同,属既定行为);记忆中的尺寸仅对上次使用的模型保证有效。
- 若重装后仍出现「无法选择自定义模型」,请提供 `~/Library/Application Support/ai.reveric.debug/logs/latest.log` 进一步排查(关注弹窗打开时 image 协议解析与模型 options 列表)。
