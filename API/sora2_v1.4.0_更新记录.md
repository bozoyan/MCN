## 更新内容

### 1. 视频提示词输入框优化

#### 问题描述
原设计的提示词输入框存在以下问题：
- 高度为最小高度 60px，导致占位符文字显示不全
- 字体大小偏小，可读性不够
- 行间距不够舒适
- 整体视觉效果不够精致

#### 解决方案
重新调整了提示词输入框的尺寸和样式：

### 2. 具体改进

#### 2.1 高度调整
```python
# 修改前
self.prompt_edit.setMinimumHeight(60)

# 修改后
self.prompt_edit.setFixedHeight(80)
```

**改进点**：
- 从最小高度改为固定高度，避免布局抖动
- 高度从 60px 增加到 80px，更适合显示多行提示
- 保持紧凑性，不会占用过多垂直空间

#### 2.2 字体样式优化
```python
self.prompt_edit.setStyleSheet("""
    QTextEdit {
        font-size: 14px;
        line-height: 1.5;
        padding: 8px;
    }
""")
```

**新增样式**：
- **字体大小**：14px（比默认稍大，提高可读性）
- **行高**：1.5（更舒适的阅读体验）
- **内边距**：8px（文字与边框保持适当距离）

### 4. 用户体验提升

#### 4.1 可读性增强
- **字体更大**：14px 字体在各种屏幕上都更清晰
- **行高舒适**：1.5 的行高符合阅读习惯
- **视觉呼吸**：8px 内边距让文字不会紧贴边框

#### 4.2 输入体验优化
- **固定高度**：避免输入时高度变化导致的界面抖动
- **适当高度**：80px 可以显示 3-4 行提示文字，足够输入详细提示
- **保持紧凑**：不会占用过多垂直空间，留出更多区域给其他控件

#### 4.3 整体协调性
- 与其他输入组件（宽高比选择、模式选择）高度更协调
- 与深色主题更加融合
- 符合现代 UI 设计规范

### 5. 技术实现

#### 5.1 样式表设计
```css
QTextEdit {
    font-size: 14px;        /* 字体大小 */
    line-height: 1.5;       /* 行高倍数 */
    padding: 8px;           /* 内边距 */
}
```

**设计考虑**：
- 字体大小 14px 是中文显示的最佳实践
- 行高 1.5 提供了良好的阅读体验
- 8px 内边距符合 8px 网格系统

#### 5.2 高度计算
- 固定高度：80px
- 内边距：8px × 2 = 16px
- 可用文本区域：64px
- 每行高度：14px × 1.5 = 21px
- 约可显示：3 行文字
